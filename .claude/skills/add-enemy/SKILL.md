# 적 에이전트 추가

적 1종은 **문서 → 데이터 → 코드** 순서로 추가한다. 순서를 바꾸면 반드시 어긋난다.

## 0단계 — 원소 고르기 ★

적은 **불안정·방사성·유해 원소**에서 이름을 가져온다(기획서 §9.1). 안정한 원소인 플레이어·무기와의 대비가 세계관(§1.3)을 성립시킨다.

> **원자번호가 그 적의 수학적 성격과 일치하는 원소만 고른다.**

원자번호에서 수학적 근거를 못 찾으면 그 원소를 쓰지 않는다. 쓸 만한 성격 — 소수, 완전수, 제곱수, 삼각수, 고도합성수, 회문수.

**이미 쓴 원소는 재사용하지 않는다.** 기획서 §5.2·§6.2·§7·§8·§9.2·§9.3 표 전체를 확인한다.

아직 안 쓴 불안정 원소 예시 — 프랑슘(87, 가장 불안정한 자연 원소), 라듐(88), 플루토늄(94), 테네신(117), 프로메튬(61, 소수), 비소(33, 회문수), 수은(80), 스트론튬(38).

## 1단계 — 명세 작성 (문서가 먼저다)

`docs/10-게임디자인/12-에이전트-적명세.md`에 항목을 추가한다. **모든 필드를 채운다. 빈 칸은 `TBD`.**

```markdown
### E-08 프랑슘 유도체 (Fr)

| 필드 | 값 |
| --- | --- |
| id | `francium` |
| 원소 / 원자번호 | Fr / 87 |
| 수학적 근거 | 87 = 3 × 29. 가장 불안정한 자연 원소 — 22분이면 사라진다 |
| 등장 | 5:00~ |
| HP / 이동속도 / 접촉피해 | 70 / 30 / 5 |
| AI | 사거리 200 유지, 3초마다 유도탄 1발 |
| 드롭 | 양성자 조각 5 |
| 스프라이트 | 원 r=16, 눈 1개, `#7E57C2`, 방사선 표식 |
| 근거 | 중반에 "거리를 좁혀야 하는" 압박을 만드는 유일한 유도형 |
```

**`근거` 칸이 핵심이다.** 이 적이 플레이어에게 무엇을 가르치거나 강요하는지 한 줄로 못 쓰면, 그 적은 필요 없다.

## 2단계 — 밸런스 데이터

`src/data/enemies.ts`에 문서와 **동일한 수치**로 항목을 추가한다.

```ts
export const ENEMIES = {
  francium: {
    id: 'francium',
    element: 'Fr', atomicNumber: 87,   // 스프라이트 라벨·도감이 쓴다
    spawnAtSec: 300,
    hp: 70, speed: 30, contactDamage: 5,
    xp: 5,
    radius: 16, color: '#7E57C2', eyes: 1,
    ai: 'ranged',
  },
};
```

## 3단계 — AI 구현

`src/systems/enemy-ai.ts`에 `ai` 종류가 없으면 추가한다. **기존 종류로 표현 가능하면 새로 만들지 않는다.**

현재 AI 종류: `chase`(직선 추격), `charge`(정지 후 돌진), `tank`(저속·전방 감쇄), `split`(사망 시 분열), `ranged`(사거리 유지·발사), `flee`(도주).

성능 규칙을 지킨다 — **업데이트 루프 안에서 할당 금지, 오브젝트 풀 사용, 공간 해시로 충돌.**

## 4단계 — 스폰 테이블

`src/data/waves.ts`의 타임라인에 등장 시각을 넣는다. 기획서 §4 타임라인과 일치해야 한다.

## 5단계 — 검증

```powershell
npm run lint
npm run test
npm run dev        # 실제로 등장하는지 눈으로 확인
```

적을 추가하면 동시 존재 개체가 늘어난다. **`perf-check` 스킬로 적 300체 시나리오를 측정한다.**
