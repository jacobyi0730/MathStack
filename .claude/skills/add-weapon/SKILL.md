# 무기 추가

무기는 **패시브 짝꿍과 각성까지 한 세트**다. 셋 중 하나만 추가하면 각성 표에 구멍이 난다.

## 0단계 — 원소 고르기 ★

이름은 **화학 원소**에서 가져온다(기획서 §6.1). 규칙은 하나다.

> **원자번호가 그 무기의 수학적 성격과 일치하는 원소만 고른다.**

원자번호에서 수학적 근거를 못 찾으면 **그 원소를 쓰지 않는다.** 분위기만 빌린 이름은 이 프로젝트에서 반려된다.

쓸 만한 수학적 성격 — 소수, 완전수(6·28·496), 제곱수(4·9·16·25·36·49·64·81·100), 세제곱수(8·27·64), 삼각수(3·6·10·15·21·28), 고도합성수(12·24·36·48·60), 회문수(11·22·33), 진법의 밑(2·10·12·60).

**이미 쓴 원소는 재사용하지 않는다.** 기획서 §5.2·§6.2·§7·§8의 표 전체를 확인한다.

## 1단계 — 명세 작성

`docs/10-게임디자인/13-스킬-무기명세.md`의 세 표를 **모두** 갱신한다.

**무기 표** — `원자번호`와 `수학적 근거` 칸을 반드시 채운다.

| ID | 이름 | 원자번호 | 수학적 근거 | 형태 | 데미지 | 쿨타임 |
| --- | --- | --- | --- | --- | --- | --- |
| `titanium_strike` | **타이타늄 강타** (Ti) | 22 | 회문수 — 앞뒤가 같은 수 | 근접 강타 | 26 | 2.8s |

**패시브 표** — 짝꿍은 **1:1 고정**이라 기존 8개는 전부 임자가 있다. 새 무기에는 **새 보조 아이템이 필요하다.**

| ID | 이름 | 원자번호 | 수학적 근거 | 효과 |
| --- | --- | --- | --- | --- |
| `zinc` | **아연 보호막** (Zn) | 30 | 2×3×5 — 가장 작은 세 소수의 곱 | 넉백 저항 +20% |

**각성 표** — 그 원소가 실제로 변하는 상위 형태를 쓴다.

| 기본 무기 | + 보조 | → 각성 무기 | 변화의 근거 | 효과 |
| --- | --- | --- | --- | --- |
| 타이타늄 강타 | 아연 보호막 | **티타늄 합금 강타** | 타이타늄 → 합금 | 범위 2배 누적, 3회 후 초기화 |

## 2단계 — 밸런스 데이터

`src/data/weapons.ts`에 문서와 동일한 수치로 추가한다. 레벨 1~5 성장은 규칙을 따른다 — **Lv당 데미지 +20%, Lv3에서 투사체/범위 +1단계, Lv5에서 각성 자격.**

```ts
titanium_strike: {
  id: 'titanium_strike',
  element: 'Ti', atomicNumber: 22,   // 도감 화면에서 쓴다
  damage: 26, cooldown: 2.8,
  pattern: 'melee_arc',
  evolvesWith: 'zinc',
  evolvesTo: 'titanium_alloy',
},
```

`element`와 `atomicNumber`를 빠뜨리지 않는다. 아이템 도감이 이 값으로 "22는 앞뒤가 같은 회문수야"를 보여준다.

## 3단계 — 발사 패턴 구현

`src/systems/weapons.ts`에 `pattern`이 없으면 추가한다.

현재 패턴: `projectile`(전방 투사체), `pierce`(직선 관통), `orbit`(궤도 회전), `wave`(원형 확산), `aura`(근접 지속), `bomb`(착탄 분열), `boomerang`(왕복), `spread`(다탄 확산).

**투사체는 반드시 오브젝트 풀에서 꺼낸다.** 무기는 초당 수십 발을 만들므로 여기서 할당하면 프레임이 무너진다.

## 4단계 — 각성 구현

`src/systems/evolution.ts`에 각성 조건과 결과를 등록한다. 조건은 `무기 Lv.5 + 짝꿍 패시브 Lv.3`이며, 충족 시 **다음 레벨업 선택지에 확정 등장**한다(보스 상자 방식 아님).

## 5단계 — 검증

```powershell
npm run lint && npm run test && npm run dev
```

실제로 각성까지 도달해본다. 기획서 §11 기준 **7~8분경 각성 1개**가 목표다.

## 완료 조건

- [ ] **원자번호에 수학적 근거가 있고 표에 적혀 있다** (§0단계)
- [ ] 이미 쓴 원소를 재사용하지 않았다
- [ ] 무기·패시브·각성 세 표가 모두 갱신됐다
- [ ] 짝꿍 패시브가 다른 무기와 중복되지 않는다
- [ ] `element`·`atomicNumber` 필드가 데이터에 있다
- [ ] 문서 수치와 `src/data/weapons.ts`가 일치한다
- [ ] 투사체가 오브젝트 풀을 쓴다
- [ ] 실제 플레이로 각성 도달을 확인했다
- [ ] 문서·데이터·코드를 **한 커밋**으로 묶었다
