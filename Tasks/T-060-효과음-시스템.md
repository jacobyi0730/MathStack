# T-060 · 효과음 시스템과 CC0 음원

## 요청

전투에 사운드를 넣고 싶다. 무료 사운드를 내려받아 넣을 수 있는가.

## 선행 판단 — 기획 미결 사항 해소

[01-기반 §18](../docs/01-기반.md) #4 "사운드 — 교실 사용 고려해 기본 음소거 여부"가 미결이었다. 이번에 셋을 정했다.

| 항목 | 결정 | 근거 |
| --- | --- | --- |
| 범위 | **효과음만.** BGM 은 v1 제외 | 10분 세션 내내 도는 배경음은 교실에서 부담이 크고, 번들·대역폭 비용도 효과음의 몇 배다 |
| 기본 볼륨 | **50%** | 0 이 기본이면 소리 없는 게임으로 보이고, 100 은 여러 대가 같이 켜졌을 때 시끄럽다 |
| 라이선스 | **CC0 만** | 교실 배포에서 저작자 표시 의무가 없어야 한다 |

## 완료 조건 (DoD)

- [x] 무료(CC0) 음원을 실제로 내려받아 저장소에 넣었다.
- [x] 모든 주요 사건에 효과음이 붙는다 — 타격·처치·피격·레벨업·아이템·보스 스킬·문제 결과.
- [x] 게임 루프에서 오디오 객체를 만들지 않는다.
- [x] 같은 프레임에 겹친 요청이 소음이 되지 않는다.
- [x] 첫 사용자 조작에서 오디오가 해금되고, 그 전에 음원을 미리 받아 둔다.
- [x] 소리 크기 설정(끄기/보통/크게)이 저장된다.
- [x] 오디오를 못 쓰는 환경에서도 게임이 그대로 돌아간다.
- [x] `npm run typecheck`, `npm run lint`, `npm run test`, `npm run build` 가 통과한다.

## 결과

- 음원: **Kenney CC0** 팩 5종에서 24개 선정 → 모노 AAC 64kbps `.m4a` 재인코딩. `public/audio/` 총 **220KB**. 출처 대응표는 `public/audio/CREDITS.md`
- 구현
  - `src/audio/cues.ts` — 큐 카탈로그와 크기·간격·동시수·우선순위 정본
  - `src/audio/sfx.ts` — Web Audio 재생기(선로딩·해금·피치 흔들기·패닝·목소리 상한), 오디오 없는 환경용 무음 재생기
  - `src/audio/queue.ts` — 무할당 요청 큐
  - `src/ui/settings.ts` — 소리 크기 3단
  - `src/main.ts` — 타이틀 화면 중 선로딩, 첫 입력 해금, 프레임 끝 배출
  - `src/ui/title.ts` — **설정 화면 진입점.** `createSettingsView` 는 T-027 부터 있었지만 어디서도 열리지 않아 사실상 죽은 화면이었다. 소리를 끌 길이 없으면 교실에서 못 쓴다
- 테스트: `tests/src/sfx.test.ts` — 카탈로그 무결성, 빈도↔크기 역관계, 30회 요청이 1회 재생으로 뭉침, 거리 감쇠·패닝 / `tests/src/settings.test.ts` 갱신 / `tests/src/title.test.ts` — 설정 진입점 회귀 가드
- 문서: `docs/30-기술/37-사운드-피드백.md` §5, `docs/01-기반.md` §18 #4, `docs/05-세션-운영.md` §14.4

## 설계 결정

- **왜 다운로드인가.** Web Audio 로 즉석 합성하면 파일이 0바이트지만, 합성음은 초등 대상 게임에서 "장난감 소리"로 들린다. CC0 실음원은 220KB로 예산 안이고 라이선스 의무가 없다.
- **왜 `.m4a` 인가.** 원본은 Ogg Vorbis 지만 iOS Safari 지원이 늦었다. 이 게임은 모바일에서도 돌아야 하므로 AAC/MP4 로 통일했다.
- **소리는 루프 밖에서 낸다.** `AudioBufferSourceNode` 는 한 번 쓰고 버리는 객체라 재생마다 할당이 생긴다. 시뮬레이션은 고정 배열에 요청만 쌓고 프레임 끝에 한 번 비운다 — 적 서른이 동시에 죽어도 노드는 하나다.
- **크기는 빈도의 역수.** 잡몹 타격음(0.16)이 보스 처치음(0.9)보다 다섯 배 작아야 겨우 같은 크기로 들린다.
- **오답 소리는 부저가 아니다.** 부드럽게 내려가는 음을 쓴다. 부저를 쓰면 "오답은 처벌이 아니라 학습이다"(AGENTS.md 설계 원칙 3)가 소리 하나로 깨진다.

## 남은 것

- BGM 은 넣지 않았다. 넣는다면 챕터 전환(3분·6분)에 맞춘 3트랙이 자연스러우나, 교실 부담과 대역폭을 다시 판단해야 한다.
- 실기기에서 소리 크기 기본값 50%가 적절한지는 사람이 들어 봐야 한다.
