# T-046. mds/14 작업8 개선

## 요청

1. 8분이 되면 게임이 멈추는 문제 수정
2. 챕터마다 배경 변경
3. 보스 상대 중에는 다른 몬스터 제거, 보스만 상대
4. 보스 능력치 상향
5. 각성한 무기는 다시 보상 선택지에 나오지 않게 하기
6. 첫 화면에 랭킹 버튼 추가
7. 첫 화면에 이어하기 버튼 추가, 생존 종료 시 자동 저장, 이어하기로 복귀

## 완료 조건 (DoD)

- [x] 8분 초월 수련 구간에서 게임이 멈춘 채 방치되지 않고 문제 3개와 보상 처리가 끝난다.
- [x] 0~3분, 3~6분, 6분 이후 배경이 구분된다.
- [x] 보스 등장 시 일반 적이 정리되고, 보스 생존 중 일반 적 스폰이 멈춘다.
- [x] 보스 HP/피해가 문서와 데이터에서 함께 상향된다.
- [x] 각성으로 대체된 기본 무기와 이미 가진 각성 무기가 레벨업 선택지에 다시 나오지 않는다.
- [x] 타이틀에서 localStorage 랭킹 TOP 5를 볼 수 있다.
- [x] 생존 중 종료 시 이어하기 데이터가 저장되고, 타이틀의 이어하기로 같은 학년/캐릭터 진행도를 복구한다.
