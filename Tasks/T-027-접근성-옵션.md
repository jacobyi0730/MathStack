# T-027 · 접근성 옵션

## 목표

교실에는 다양한 아이가 있다. **읽기 속도가 느린 아이, 빛에 민감한 아이, 마우스가 어려운 아이**가 이 게임을 할 수 있어야 한다.

## 범위 (기획서 §14.4)

- [ ] `src/ui/settings.ts` — 설정 화면
- [ ] **"천천히 풀기"** — 문제 시간 제한 해제
- [ ] **화면 효과 강도** — 흔들림·섬광 0% / 50% / 100%
- [ ] **글자 크기** — 보통 / 크게 (문제 본문 24px → 32px)
- [ ] 키보드 전용 조작 — 선택지 `1`~`4`, 확인 `Enter`
- [ ] 설정을 `localStorage`에 저장

## 전역 점검 항목

기존 화면 전체를 훑어 아래를 확인하고 위반을 고친다.

| 항목 | 기준 |
| --- | --- |
| 명도 대비 | 모든 텍스트 **4.5:1** 이상 |
| 색 단독 정보 | 금지. 정답/오답·체력 상태에 아이콘·모양 병기 |
| 터치 타깃 | 최소 **56px** |
| 포커스 표시 | 키보드 탐색 시 현재 위치가 보인다 |
| 애니메이션 | `prefers-reduced-motion` 존중 |

## "천천히 풀기"의 의미

시간 제한은 게임 리듬을 위한 것이지 평가 장치가 아니다. 해제해도 **보상은 동일**하다. 시간 제한 해제를 페널티와 묶으면 옵션의 의미가 없어진다.

## 완료 조건 (DoD)

- [ ] 4개 옵션이 전부 동작하고 저장된다
- [ ] "천천히 풀기" 시 타이머가 사라지고 보상은 동일하다
- [ ] 화면 효과 0%에서 흔들림·섬광이 완전히 없다
- [ ] `prefers-reduced-motion: reduce`를 존중한다
- [ ] 마우스 없이 키보드만으로 게임을 시작해 한 문제를 풀 수 있다
- [ ] 모든 텍스트 명도 대비 4.5:1 이상 (검사 도구로 확인)
- [ ] `npm run lint` · `npm run test` 통과

## 주의

접근성을 마지막에 붙이면 대개 "설정 화면만 만들고 실제로는 안 되는" 상태가 된다. **실제로 키보드만 잡고 한 판을 끝까지 해본다.**
