# T-023 · 인게임 HUD

## 목표

전투 중 필요한 정보만 화면에 띄운다. **게임 화면을 가리지 않으면서 한눈에 읽혀야 한다.**

## 레이아웃 (기획서 §14.2)

```
┌────────────────────────────────────────────────────┐
│  ⏱ 04:32        Lv.11   ████████░░  237/305        │
│  ❤ 82/120                          ⚔ 342  ✓ 9/11   │
├────────────────────────────────────────────────────┤
│                     [ 게임 화면 ]                   │
├────────────────────────────────────────────────────┤
│  액티브  [＋5][－3][×2][ ][ ][ ]                    │
│  패시브  [🧲3][🔢2][👟1][ ][ ][ ]                   │
└────────────────────────────────────────────────────┘
```

## 범위

- [ ] `src/ui/hud.ts` — 상단 상태 바, 하단 슬롯 바
- [ ] 생존 시간 / 레벨 / 경험치 게이지
- [ ] 체력 바 — 피격 시 짧게 붉게 점멸
- [ ] 처치 수 / 정답 수 (`✓ 9/11` = 11문제 중 9개 정답)
- [ ] 무기 6슬롯 · 패시브 6슬롯, 각 레벨 배지
- [ ] **각성 가능 상태 표시** — 조건 충족 무기에 반짝임 (T-013 연동)

## 성능

HUD는 DOM이다. **매 프레임 DOM을 갱신하지 않는다.**

- 값이 바뀔 때만 갱신 (경험치·체력은 변동이 잦으므로 **10프레임에 1회**로 스로틀)
- 시간 표시는 초 단위가 바뀔 때만
- 슬롯은 무기/패시브 변경 시에만

## 완료 조건 (DoD)

- [ ] 6개 정보가 전부 표시되고 실시간으로 갱신된다
- [ ] 각성 가능 무기가 시각적으로 구분된다
- [ ] DOM 갱신이 매 프레임 일어나지 않는다 (프로파일러로 확인)
- [ ] HUD가 게임 화면의 중앙 영역을 가리지 않는다
- [ ] 태블릿 가로 해상도에서 레이아웃이 깨지지 않는다
- [ ] `npm run lint` · `npm run test` 통과

## 주의

HUD를 캔버스에 그리고 싶은 유혹이 있지만 **DOM 오버레이로 유지한다.** 텍스트 렌더 비용이 캔버스가 훨씬 비싸고, 접근성(스크린 리더·확대)도 DOM이 낫다.
