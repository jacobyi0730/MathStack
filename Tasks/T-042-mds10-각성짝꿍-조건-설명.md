# T-042. mds/10 각성 짝꿍 설명과 조건 보정

## 범위

- 무기 선택지 설명 아래에 각성 짝꿍 보조무기 표시
- 보조무기 선택지 설명 아래에 연결되는 각성 무기 표시
- 시작 무기 선택 카드에도 각성 짝꿍 표시
- 각성 조건을 `무기 Lv.5 + 짝꿍 보조무기 보유`로 완화
- 관련 문서와 테스트 갱신

## 결과

- 보조무기는 Lv.1로 보유만 해도 각성 조건을 만족한다.
- 각성 가능한 무기·보조무기 선택지는 짝꿍과 결과 각성 무기를 함께 보여준다.
