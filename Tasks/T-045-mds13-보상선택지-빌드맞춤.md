# T-045. mds/13 보상 선택지 빌드 맞춤

## 범위

- 레벨업 보상 선택지를 랜덤 1개 + 현재 빌드 맞춤 선택지 중심으로 재구성
- 맞춤 선택지에 현재 보유 무기 강화와 해당 무기의 각성 짝꿍 보조무기를 우선 배치
- 각성 가능 선택지의 우선 노출 규칙 유지
- 회귀 테스트와 문서 갱신

## 결과

- 3개 보상 선택지는 랜덤 1개와 보유 무기 강화/각성 짝꿍 후보 2개로 구성된다.
- 2개 보상 선택지에서도 현재 빌드에 맞는 후보가 최소 1개 들어간다.
