# T-021 · 퀴즈 모달 UI

## 목표

레벨업 시 뜨는 문제 화면을 만든다. **아이가 하루에 20번 보는 화면이다.** 여기가 불편하면 게임 전체가 불편하다.

## 규격 (기획서 §14.3)

| 항목 | 기준 |
| --- | --- |
| 게임 상태 | **완전 정지**, 배경 40% 어둡게 |
| 시간 표시 | 상단 **링 게이지**, 5초 남으면 붉게 점멸 |
| 문제 글자 | 최소 **24px** |
| 선택지 | 2×2 그리드, 버튼 최소 높이 **56px** |
| 분수 | **세로 분수**로 렌더 (`3/5` 형태 금지) |
| 정답 연출 | 초록 플래시 0.3초 |
| 오답 연출 | 붉은 흔들림 + 해설 카드 슬라이드 인 |

## 범위

- [ ] `src/ui/quiz-modal.ts` — 모달 표시/숨김, 선택지 렌더
- [ ] `src/ui/fraction.ts` — 세로 분수 렌더 (분자/가로선/분모)
- [ ] 타이머 링 게이지 (SVG)
- [ ] 재도전 흐름 — 오답 시 해설 **3초 노출** 후 재시도
- [ ] `number_input` 형식 지원 (숫자 키패드)
- [ ] 스킬 선택 화면 연동 (3택/2택)

## 세로 분수

교과서 표기를 따른다. 아이는 `3/5`를 "3 나누기 5"로 읽는 경우가 있다.

```
 3        3
───  ✅  ───  ❌  3/5
 5        5
```

대분수(`1과 2/3`)도 처리해야 한다.

## 접근성

- 명도 대비 **4.5:1** 이상
- 정답/오답에 **아이콘 병기** (색만으로 전달 금지)
- 키보드로 모든 선택지 접근 가능 (`1`~`4` 단축키)

## 완료 조건 (DoD)

- [ ] 모달이 뜨면 게임이 완전히 멈춘다
- [ ] 분수가 세로로 렌더된다 (진분수·가분수·대분수 전부)
- [ ] 타이머가 15초에서 시작해 5초에 점멸한다
- [ ] 오답 시 해설이 뜨고 재도전이 가능하다
- [ ] **오답 시 체력이 줄지 않는다**
- [ ] 태블릿 가로에서 버튼이 56px 이상이다 (실기기 또는 DevTools 확인)
- [ ] `npm run lint` · `npm run test` 통과

## 주의

**실제로 띄워서 눈으로 본다.** 특히 분수 렌더와 버튼 크기는 코드만 봐서는 알 수 없다. `npm run dev`로 확인한다.
