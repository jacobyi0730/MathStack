# T-001 · 프로젝트 스캐폴딩

## 목표

[31-아키텍처 §4](../docs/30-기술/31-아키텍처.md) 디렉터리 구조를 실제 파일로 만든다. 이후 모든 태스크가 이 뼈대 위에 올라간다.

**언어는 TypeScript 하나다.** 빌드 타임(`tools/`)과 런타임(`src/`)이 같은 툴체인을 쓴다.

## 범위

- [ ] `package.json` — Vite, TypeScript, tsx, Zod, Vitest, ESLint, Prettier
- [ ] `tsconfig.json` — `strict: true`, `shared/`·`tools/`·`src/` 경로 별칭
- [ ] `vite.config.ts` — `publicDir: 'public'`, 빌드 출력 `dist/`
- [ ] `.gitignore` — `public/data/`, `dist/`, `node_modules/`
- [ ] `index.html` + `src/main.ts` 최소 부트스트랩
- [ ] 빈 디렉터리: `shared/`, `content/{templates,fixed}/`, `tools/`, `src/{engine,systems,entities,quiz,ui,data}/`, `tests/{tools,src}/`
- [ ] `README.md` — 설치·실행만

## npm 스크립트

`package.json`에 모든 진입점을 모은다. Netlify가 이 이름들을 그대로 부른다.

```jsonc
{
  "scripts": {
    "dev": "vite",
    "build": "vite build",
    "preview": "vite preview",
    "build:bank": "tsx tools/build-bank.ts",
    "validate:bank": "tsx tools/validate-bank.ts",
    "build:balance": "tsx tools/build-balance.ts",
    "typecheck": "tsc --noEmit",
    "lint": "eslint .",
    "test": "vitest run"
  }
}
```

## 빌드 타임 전용 의존성

`fraction.js`·`decimal.js`는 **`tools/`에서만** import 한다. `src/`가 이것을 참조하면 번들에 새어 들어가므로, `devDependencies`에 둔다.

| 경로 | 내용 |
| --- | --- |
| `package.json`, `tsconfig.json`, `vite.config.ts` | 툴체인 |
| `.gitignore` | 생성물 제외 |
| `index.html`, `src/main.ts` | 캔버스 하나 띄우는 최소 코드 |

## 완료 조건 (DoD)

- [ ] `npm install && npm run dev` — 캔버스가 보인다
- [ ] `npm run build` 성공, `dist/`에 산출
- [ ] `npm run typecheck` · `npm run lint` 통과 (검사할 코드가 없어도 설정 오류가 없어야 한다)
- [ ] `npm run test` 실행됨 (테스트 0개여도 성공해야 한다)
- [ ] `git status`에 `public/data/`·`dist/`·`node_modules/`가 안 보인다

## 주의

**`public/data/`를 커밋하지 않는다.** 생성물이며, 여기서 `.gitignore`를 빠뜨리면 이후 모든 커밋에 수천 줄 JSON이 딸려온다.

### 설계와 달라진 점

1. **`tsconfig.json`에서 `baseUrl`을 뺐다.** 설치된 TypeScript가 6.0이고 `baseUrl`이 폐기(TS5101)되어 typecheck가 실패했다. `paths`를 `./` 접두 상대 경로로 바꿔 해결. 기능 차이는 없다.
2. **ESLint에 프로젝트 전용 규칙을 추가했다.** 원래 범위에 없었지만, AGENTS.md §2의 규칙 중 기계로 잡을 수 있는 것을 도구로 옮기는 편이 낫다고 판단했다 — 자세한 건 아래.
3. **`git init`을 함께 했다.** `.gitignore` 동작을 검증하려면 저장소가 필요했다. 커밋은 하지 않았고 스테이징도 해제했다.

### lint로 옮긴 절대 규칙

| AGENTS.md §2 | ESLint 규칙 | 적용 범위 |
| --- | --- | --- |
| 규칙 2 (타입 계약) | `@typescript-eslint/no-explicit-any: error` | 전체 |
| 규칙 3 (게임 루프 네트워크 금지) | `no-restricted-globals: fetch` | `src/engine`·`systems`·`entities` |
| 결정적 전개 (36-코딩컨벤션 §3) | `no-restricted-properties: Math.random` | `tools/`·`content/` |
| 빌드 타임 의존성 격리 (31-아키텍처 §8) | `no-restricted-imports: fraction.js·decimal.js` | `src/` |

각 규칙의 `message`에 어긋난 스펙 번호를 넣어, 걸렸을 때 어디를 읽어야 하는지 바로 알 수 있게 했다.

### 부수 산출물

- **`.gitattributes`** — Windows 환경이라 `eol=lf` 고정. 없으면 CRLF 혼입으로 diff가 통째로 뒤집힌다. `mds/` 기존 파일에서 실제로 CRLF 경고가 떴다.
- `git config core.quotepath false` — 한글 파일명이 8진수 이스케이프로 보이던 문제 해결.
