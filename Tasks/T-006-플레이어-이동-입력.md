# T-006 · 플레이어 이동 & 입력

## 목표

**이동만 하는** 조작을 구현한다. 공격 입력은 없다 — 이 게임에 공격 버튼은 존재하지 않는다.

## 범위

- [ ] `src/engine/input.ts` — WASD / 방향키 / 드래그(터치·마우스) 통합
- [ ] 세 입력이 **같은 방향 벡터**로 정규화되어 나온다
- [ ] `src/entities/player.ts` — 이동, 체력, 무기·패시브 슬롯 6+6
- [ ] `src/systems/movement.ts` — 속도 적용, 맵 경계 처리
- [ ] 플레이어 4종 특성 (기획서 §5.2)

| 캐릭터 | 원자번호 | 색 | 특성 |
| --- | --- | --- | --- |
| 수소 동글이 (H) | 1 | `#4CAF50` | 최대 체력 +10% |
| 네온 동글이 (Ne) | 10 | `#2196F3` | 이동속도 +15%, 체력 −10% |
| 탄소 동글이 (C) | 6 | `#FF9800` | 투사체 수 +1, 공격력 −10% |
| 산소 동글이 (O) | 8 | `#9C27B0` | 공격 범위 +20%, 쿨타임 +10% |

캐릭터는 시작 무기의 원소를 쓴다. `element`·`atomicNumber` 필드를 데이터에 함께 넣는다 — 선택 화면과 도감이 이 값을 쓴다.

## 입력 규칙

- 대각선 이동 속도가 직선보다 빠르면 안 된다 (벡터 정규화)
- 드래그는 **플레이어 기준 상대 방향** — 화면 절대 좌표로 순간이동시키지 않는다
- 키를 떼면 즉시 정지 (관성 없음). 조작이 단순해야 아이가 문제에 집중한다

## 완료 조건 (DoD)

- [ ] 세 입력 방식 모두 동작하고 결과가 동일하다
- [ ] 대각선 속도가 직선과 같다
- [ ] 캐릭터 4종의 특성 수치가 `src/data/`와 문서에서 일치한다
- [ ] 동공이 이동 방향을 따라간다 (T-004 연동)
- [ ] `npm run lint` · `npm run test` 통과

## 주의

공격 관련 입력을 만들지 않는다. "나중에 대시라도 넣자"는 제안이 나오면 기획서 §1의 **조작: 이동만**을 근거로 거절한다.
