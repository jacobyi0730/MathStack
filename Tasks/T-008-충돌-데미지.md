# T-008 · 충돌 판정 & 데미지

## 목표

공간 해시를 사용한 충돌 판정과 데미지 처리를 구현한다. **O(n²) 전수 비교는 금지다.**

## 범위

- [ ] `src/systems/collision.ts` — 공간 해시 질의 기반 원-원 충돌
- [ ] 판정 쌍: `투사체↔적`, `적↔플레이어`, `플레이어↔픽업`
- [ ] `src/systems/damage.ts` — 데미지 적용, 무적 프레임, 넉백
- [ ] 데미지 텍스트 (풀에서 획득)
- [ ] 적 사망 처리 → 양성자 조각 드롭
- [ ] 플레이어 피격 시 **0.5초 무적** (연속 접촉으로 즉사 방지)

## 충돌 규칙

- 원-원 판정. **제곱근을 쓰지 않는다** — 거리 제곱으로 비교한다
- 적끼리는 충돌하지 않는다 (밀어내기 없음). 300체 밀집 시 비용을 감당할 수 없고, 원작도 겹쳐 그린다
- 접촉 피해는 **초당 피해**로 환산한다. 프레임마다 적용하면 60배가 된다

## 완료 조건 (DoD)

- [ ] 투사체가 적에게 맞고 데미지가 들어간다
- [ ] 접촉 피해가 초당 기준으로 정확하다 (프레임률과 무관)
- [ ] 무적 프레임 중 연속 피격되지 않는다
- [ ] 적 사망 시 양성자 조각이 드롭되고 풀로 반환된다
- [ ] 충돌 후보 수가 전체 엔티티 수보다 한 자릿수 이상 작다
- [ ] `perf-check` — 적 300체 + 투사체 200개에서 충돌 구간 **6ms 이내**
- [ ] `npm run lint` · `npm run test` 통과

## 주의

충돌은 이 게임에서 가장 비싼 구간이다. 구현 후 반드시 `perf-check`로 구간별 ms를 확인한다. 6ms를 넘으면 셀 크기부터 조정한다.

## 결과

- 구현: `src/systems/collision.ts`, `src/systems/damage.ts`, `src/engine/state.ts`, `src/entities/player.ts`, `src/main.ts`
- 테스트: `tests/src/collision.test.ts`, `tests/src/damage.test.ts`
- 검증: `npm run typecheck`, `npm run lint`, `npm run test`(120개), `npm run build:bank`, `npm run validate:bank`, `npm run build` 통과
- 메모: 투사체·픽업 엔티티는 아직 없어서 `findEnemyHit()`·`applyEnemyDamage()`·`combat.pendingXp/pendingShards` 연결 지점으로 구현했다. 실제 투사체 풀과 조각 드롭 엔티티는 T-009/T-010에서 이어 붙인다.
