# T-034. 근접 무기 범위·접촉 피해·퀴즈 시간 제한

## 배경

플레이 중 탄소 고리와 철 결계의 범위가 너무 좁고, 철 결계는 레벨업 시 범위가 줄어드는 것처럼 보였다. 또한 적과 주인공이 충돌해도 체력 변화가 거의 보이지 않았고, 수학 퀴즈에는 시간 제한 UI가 남아 있었다.

## 범위

- 탄소 고리, 철 결계과 각성형 근접 무기의 반경을 약 두 배로 확대
- 철 결계 레벨업 시 범위가 줄지 않는 회귀 테스트 추가
- 적 접촉 피해를 프레임 단위 미세 피해가 아니라 충돌 1회당 보이는 피해로 변경
- 퀴즈 모달의 시간 제한 UI 제거
- 관련 기획 문서와 TodoList 기록 갱신

## DoD

- [x] 탄소 고리와 철 결계의 체감 지름이 기존 대비 약 두 배가 된다.
- [x] 철 결계 레벨업 후 범위가 줄지 않는다.
- [x] 적 접촉 시 플레이어 체력이 즉시 감소한다.
- [x] 퀴즈 모달에 남은 시간 링과 초 표시가 나오지 않는다.
- [x] 관련 테스트가 통과한다.
