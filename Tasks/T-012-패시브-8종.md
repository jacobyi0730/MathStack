## 스탯 파이프라인

- [ ] `src/systems/stats.ts` — 캐릭터 기본값 + 패시브 보정을 합산해 **파생 스탯**을 만든다
- [ ] 패시브가 바뀔 때만 재계산한다. **매 프레임 합산하지 않는다**
- [ ] 곱연산 순서를 고정한다 — `기본 × (1 + 합계비율)`. 패시브마다 곱하면 스택이 폭주한다

```ts
// 재계산 시점: 레벨업 선택 직후, 픽업 획득 시
recalcStats(state.player);
```
