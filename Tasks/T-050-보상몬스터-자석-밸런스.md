# T-050. 보상 몬스터·자석 밸런스

## 요청

1. 특별 몬스터가 너무 많이 나오므로 발생 확률을 대폭 줄인다.
2. 한 번에 필드에 존재할 수 있는 특별 몬스터 수를 최대 5마리로 제한한다.
3. 처음에는 1마리로 제한하고 시간이 지날수록 늘어나는 구조로 구간을 설정한다.
4. 자석 아이템을 먹었을 때 상자나 필드에 등장한 즉시 발동 아이템은 끌려오지 않게 한다.

## 완료 조건 (DoD)

- [x] 이리듐/아이오딘 보상 몬스터 웨이브 비중이 크게 낮아졌다.
- [x] 보상 몬스터 동시 상한이 시간대별 1→5마리로 증가한다.
- [x] 상한에 걸린 보상 몬스터 스폰은 일반 적으로 대체된다.
- [x] 자석 범위와 자석 아이템의 진공 효과는 양성자 조각에만 적용된다.
- [x] 즉시 발동 아이템은 자석에 끌려오지 않고 직접 닿아야 발동한다.
- [x] `npm run typecheck`, `npm run lint`, `npm run test`, `npm run build` 가 통과한다.
