# T-009 · 경험치 & 레벨업

## 목표

경험치 획득과 레벨업을 구현한다. **레벨업이 곧 문제 출제 트리거**이므로, 이 태스크는 수학 시스템(T-020)의 진입점이다.

## 범위

- [ ] `src/entities/pickup.ts` — **양성자 조각** 3종 (파랑 1 / 초록 5 / 빨강 20)
- [ ] `src/systems/pickup.ts` — 자석 범위 내 조각이 플레이어로 끌려옴
- [ ] `src/systems/level.ts` — 경험치 누적, 레벨업 판정
- [ ] 레벨업 시 `pause()` 후 **이벤트 발행** (선택지 UI·문제 출제가 구독)
- [ ] 회복·자기장·운석 충돌 픽업 (기획서 §10)

> 경험치가 **양성자 조각**인 것은 세계관(§1.3)과 맞물린다 — 양성자를 모아 무거워지는 것이 곧 성장이다.

## 경험치 곡선 (기획서 §11)

```
필요경험치(n) = round(5 + 1.5 × n × (n + 1) / 2)
```

| 레벨 구간 | 누적 | 목표 도달 시각 |
| --- | --- | --- |
| 1 → 5 | 42 | 0:30 ~ 2:00 |
| 6 → 10 | 237 | 2:00 ~ 4:30 |
| 11 → 15 | 707 | 4:30 ~ 7:30 |
| 16 → 20 | 1,577 | 7:30 ~ 10:00 |

**목표: 10분에 18레벨.** 첫 레벨업은 30초 이내.

## 레벨업 이벤트 계약

```ts
// 문제 출제(T-020)와 스킬 선택 UI가 이 이벤트를 구독한다
state.events.emit('levelup', { level, pendingChoices: 3 });
```

레벨업 처리 자체는 **선택지 개수를 모른다.** 정답/오답에 따라 3택·2택이 갈리는 것은 T-020의 책임이다.

## 완료 조건 (DoD)

- [ ] 양성자 조각 획득 시 경험치가 오르고 게이지가 찬다
- [ ] 자석 범위 내 조각이 끌려온다 (보조 레벨에 따라 범위 변동)
- [ ] 레벨업 시 게임이 정지하고 이벤트가 발행된다
- [ ] 실제 플레이에서 **첫 레벨업 30초 이내**, 10분 18레벨 근사
- [ ] 곡선 수치가 문서와 `src/data/`에서 일치한다
- [ ] `npm run lint` · `npm run test` 통과

## 주의

레벨업 간격이 목표를 벗어나면 곡선을 고치기 전에 **적 밀도부터 의심한다.** 후반 간격은 밀도 상승으로 유지되는 구조다 (`balance-tuner` 참조).
