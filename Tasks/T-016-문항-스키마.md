# T-016 · 공유 스키마 & 커리큘럼 테이블

## 목표

문항 데이터 계약을 **`shared/`에 한 번만** 확정한다. 이 스키마가 이후 모든 문항·검증·출제기의 기준이 되므로 먼저 못 박는다.

**계약을 두 번 정의하지 않는 것이 이 태스크의 존재 이유다.** `tools/`(굽는 쪽)와 `src/`(읽는 쪽)가 같은 Zod 스키마를 import 하고, 타입은 `z.infer`로 따라온다.

## 스키마 (기획서 §12.1)

```jsonc
{
  "id": "G4-N-016-03",           // <학년>-<영역>-<성취기준일련>-<변형>
  "grade": 4,                     // 3 | 4 | 5 | 6
  "semester": 2,                  // 1 | 2
  "domain": "수와 연산",          // 4개 영역만
  "unit": "소수의 덧셈과 뺄셈",
  "standard": "4수01-16",
  "difficulty": 2,                // 1 ~ 5
  "format": "choice",             // choice | number_input
  "stem": "3.42 + 1.8 은 얼마인가요?",
  "choices": ["5.22", "3.60", "5.20", "4.22"],
  "answer": "5.22",
  "distractorReason": ["정답", "...", "...", "..."],
  "explanation": "소수점의 위치를 맞춰 세로로 쓰고 더합니다.",
  "timeLimitSec": 15,
  "misconceptionTag": "decimal_alignment"
}
```

## 범위

- [ ] `shared/domain.ts` — `Domain` Enum **4개만** (수와 연산 / 변화와 관계 / 도형과 측정 / 자료와 가능성), `Grade` 3~6, `Difficulty` 1~5, `Semester` 1~2
- [ ] `shared/schema.ts` — `QuestionSchema`, `BankSchema`, `BalanceSchema` (Zod) + `z.infer` 타입 export
- [ ] `shared/curriculum.ts` — 기획서 §13 매핑표를 코드로
- [ ] 스키마 레벨 `refine` 검증:
  - `answer`가 `choices`에 정확히 1회 등장
  - `distractorReason.length === choices.length`
  - `misconceptionTag`가 빈 문자열이 아님
  - `standard` 형식 정규식 `^[46]수0[1-4]-\d{2}$`
- [ ] `tests/tools/schema.test.ts`

## 커리큘럼 테이블

기획서 §13의 매핑표를 **기계가 읽을 수 있는 형태**로 옮긴다. 이것이 없으면 검증기가 성취기준을 확인할 방법이 없다.

```ts
export const CURRICULUM: Record<string, StandardInfo> = {
  '4수01-16': { grade: 4, semester: 2, domain: Domain.Number,
                unit: '소수의 덧셈과 뺄셈', fitness: '◎' },
};
```

## 완료 조건 (DoD)

- [ ] 유효 문항이 `QuestionSchema.parse()`를 통과한다
- [ ] 정답 중복·근거 개수 불일치·태그 누락 문항이 **거부된다**
- [ ] `CURRICULUM`이 기획서 §13의 모든 코드를 담고 있다
- [ ] §13.5 출제 제외 코드가 `fitness: '✕'`로 표시된다
- [ ] `tools/`와 `src/` 어디에도 문항 타입 자체 정의가 없다
- [ ] `npm run typecheck` · `npm run lint` · `npm run test` 통과

## 주의

`domain`을 자유 문자열로 두지 않는다. 2015 개정의 "규칙성" 같은 옛 영역명이 섞이면 영역 균형 출제(§12.5)가 조용히 깨진다. **Enum으로 못 박아 컴파일 타임에 잡는다.**
