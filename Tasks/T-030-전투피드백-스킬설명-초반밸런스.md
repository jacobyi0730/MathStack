# T-030 · 전투 피드백 · 스킬 설명 · 초반 밸런스

## 배경

플레이 테스트에서 다음 개선점이 확인됐다.

- 적이 피해를 입어도 몇 데미지가 들어갔는지 알 수 없다.
- 스킬 선택 설명이 내부 패턴명 위주라 실제 효과를 이해하기 어렵다.
- 초반 일반 적이 기본 무기 기준 여러 대를 맞아야 죽어 성장감이 둔하다.

## 범위

- [x] `src/entities/damage-number.ts` — 데미지 숫자 고정 풀
- [x] `src/engine/state.ts`, `src/engine/renderer.ts`, `src/main.ts` — 데미지 숫자 업데이트/렌더 연결
- [x] `src/systems/damage.ts` — 적 피격 시 실제 피해량 표시
- [x] `src/systems/level-reward.ts` — 무기/패시브/각성 설명 구체화
- [x] `src/data/enemies.ts`, `src/data/waves.ts` — 초반 체력·접촉 피해·성장률 조정
- [x] 기획서에 전투 피드백, 스킬 설명 규칙, 초반 밸런스 기준 반영

## 완료 조건 (DoD)

- [x] 적 피격 시 데미지 숫자가 표시된다.
- [x] 데미지 숫자는 고정 크기 풀로 재사용된다.
- [x] 스킬 선택지는 실제 공격 방식과 능력치 증가를 설명한다.
- [x] 라돈은 기본 수소 화살 Lv.1 한 방에 죽는다.
- [x] 초반 적 체력·접촉 피해가 완만한 성장곡선에 맞게 조정된다.
- [x] `npm run typecheck` · `npm run lint` · `npm run test` · `npm run build` 통과
- [x] `npm run build:bank` · `npm run validate:bank` 통과

## 결과 메모

- 데미지 숫자 풀 96개를 추가하고 렌더러 마지막 레이어에 표시했다.
- 스킬 선택 설명을 “새 무기 추가/무기 강화/패시브 능력치/즉시 각성” 기준으로 구체화했다.
- 라돈 HP 10, 소듐 HP 24 등으로 초반 처치 템포를 낮추고 HP 성장률을 0.12로 완화했다.
