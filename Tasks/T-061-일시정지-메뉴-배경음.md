# T-061 · 일시정지 메뉴와 배경음

## 요청

환경설정 메뉴를 추가한다. 게임 중에 누르면 게임을 일시정지하고 `계속하기`, `그만하기`, `BGM 사운드와 effect 사운드 볼륨조정`, `타격감 효과 on/off` 를 제공한다.

## 선행 판단 — BGM 을 실제로 넣는다

T-060 에서 **BGM 은 v1 제외**로 정했었다. 이번 요청이 그 결정을 뒤집는다.

BGM 볼륨 슬라이더만 만들고 음악을 안 넣으면 **아무것도 하지 않는 손잡이**가 된다. 그건 없는 것보다 나쁘다 — 만져 봐도 아무 변화가 없으면 사용자는 게임이 고장 났다고 판단한다. 그래서 음악을 함께 넣기로 했다.

넣으면서 T-060 이 BGM 을 미룬 두 이유는 그대로 해결했다.

| T-060 의 우려 | 이번 대응 |
| --- | --- |
| 교실에서 배경음이 부담이다 | 기본 35%(효과음 50%보다 낮게), 일시정지 메뉴에서 **한 번에 끌 수 있다** |
| 대역폭 비용이 효과음의 몇 배다 | 볼륨 0 이면 **아예 내려받지 않는다.** 트랙 하나만 필요할 때 하나만 스트리밍한다 |

## 설계 결정

- **메뉴는 `loop.pause()` 만 부르고 재개는 `resumeAfterQuiz()` 에 맡긴다.** 문제 모달·스킬 선택도 같은 루프를 멈추므로, 메뉴가 직접 재개하면 그것들이 열려 있을 때 게임이 뒤에서 굴러간다.
- **타격감 on/off 는 `effectIntensity` 를 그대로 쓴다.** 설정을 두 벌로 두면 조용히 어긋난다. 대신 전투 중에는 50% 를 고를 수 없다 — 세 칸을 고르게 하면 판단이 길어지고 그 사이 게임은 멈춰 있다.
- **`그만하기` 에만 확인을 붙인다.** 되돌릴 수 없는 유일한 항목이다. 볼륨은 잘못 만져도 다시 만지면 된다.
- **배경음은 `<audio>` 스트리밍이다.** 80초 스테레오를 `decodeAudioData` 로 풀면 트랙당 28MB 다. 네 트랙이면 교실 크롬북이 버티지 못한다.
- **적용 버튼을 두지 않는다.** 볼륨은 들으면서 맞추는 것이라 「확인」이 있으면 두 번 만져야 한다.

## 고친 것

- 확인 블록이 `hidden` 을 줘도 보였다. 인라인 `display:grid` 가 브라우저 기본 `[hidden] { display: none }` 을 이긴다. 둘 다 손대도록 고치고 회귀 테스트를 붙였다.
- 짧은 화면에서 확인 블록이 스크롤 아래에 생겨 보이지 않았다. 열 때 패널을 맨 아래로 내린다.
