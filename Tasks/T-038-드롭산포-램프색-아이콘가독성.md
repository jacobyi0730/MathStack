# T-038. 드롭 산포·램프 단일색·아이콘 가독성

## 배경

T-037 로 모양 체계를 세웠지만 실제로 띄워 보니 세 가지가 남아 있었다.

1. **램프를 깨면 아이템이 즉시 발동됐다.** 아이템이 램프 자리에 그대로 떨어지는데, 램프를 깬 것은 플레이어가 거기 서 있었기 때문이다. 고를 틈이 없었다.
2. **램프 4종이 서로 다른 색이었다.** 색이 갈리니 "저건 다른 종류인가?" 를 먼저 묻게 됐다.
3. **수소 화살이 화면에서 안 보였다.** 반지름 5 짜리 투사체에 14px 이모지라 형체를 알 수 없었다.

## 실제로 띄워서 확인했다

추측으로 수치를 고르지 않았다. Chrome 을 헤드리스로 띄우고 CDP 로 붙어 **키 입력까지 넣어 가며** 실제 플레이 화면을 캡처해 눈으로 봤다.

| 확인한 것 | 결과 |
| --- | --- |
| 수소 화살이 실제로 발사되는가 | 30초 중 **46% 프레임**에 존재. 발사는 정상, **크기만 문제**였다 |
| 14px 이모지 | 형체를 알 수 없는 얼룩 |
| 22px 이모지 | 읽히지만 적(지름 32)보다 작아 묻힘 |
| 26px 이모지 | 적과 비슷한 무게로 읽힘 → **채택** |
| 🏹 글리프 | 26px 에서 활도 화살도 안 보임 → **💧 로 교체** |
| 양성자 조각 | **눈이 달려 있어 파란 적으로 보였다** → 눈 제거 |

## 범위

- 램프 드롭을 **120~200px 흩뿌리기** 로 변경. 기본 자력 반경(96)보다 멀어야 즉시 빨려오지 않는다
- 드롭 방향을 원 등분 + 흔들기로 배치해 한쪽으로 몰리지 않게 함
- 램프 4종을 **한 가지 색**(#C98A3C)으로 통일. 종류는 원소 기호로만 구분
- 이모지 하한 14px → **26px**, 비율 1.6 → 1.9
- `hydrogen_arrow` 아이콘 🏹 → 💧
- **양성자 조각에서 눈 제거** — T-037 에서 세운 "눈은 살아 있는 것에만" 규칙을 조각이 어기고 있었다
- 투사체의 원소 기호 라벨 제거 — 아이콘이 이미 무기를 말하고, 7px 글자는 노이즈다
