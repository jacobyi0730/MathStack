# T-029 · 월드 래핑 & 스킬 선택 버그 수정

## 배경

플레이 테스트에서 세 가지 흐름 문제가 확인됐다.

- 플레이어 이동 가능 범위가 작은 사각형처럼 느껴진다.
- 투사체가 맵 경계에 의해 위치별로 사거리가 달라진다.
- 경험치가 가득 차면 게임은 멈추지만 퀴즈/스킬 선택 흐름이 완성되지 않는다.

## 범위

- [x] `src/engine/world.ts` — 토러스 월드 좌표/거리 유틸
- [x] `src/systems/movement.ts` — 플레이어 경계 래핑
- [x] `src/entities/projectile.ts` — 투사체 경계 래핑 및 수명 기반 사거리
- [x] `src/systems/collision.ts`, `src/systems/weapons.ts`, `src/systems/enemy-ai.ts` — 경계 반대편 거리 계산
- [x] `src/main.ts` — 레벨업 퀴즈 모달 연결
- [x] `src/systems/level-reward.ts`, `src/ui/skill-choice.ts` — 퀴즈 후 스킬 선택/적용
- [x] 기획서에 월드 래핑·스킬 선택 흐름 반영

## 완료 조건 (DoD)

- [x] 플레이어는 맵 끝에서 막히지 않고 반대편으로 이어진다.
- [x] 투사체는 맵 경계 때문에 조기 삭제되지 않는다.
- [x] 적 탐색과 피격 판정은 경계 반대편을 가까운 거리로 계산한다.
- [x] 레벨업 시 퀴즈 모달이 뜬다.
- [x] 퀴즈 정답 후 스킬 선택 창이 뜨고 선택한 보상이 적용된다.
- [x] 재도전 오답도 2개 보상 선택지로 이어진다.
- [x] `npm run typecheck` · `npm run lint` · `npm run test` · `npm run build` 통과

## 결과 메모

- 월드를 8192×8192 토러스 맵으로 확장하고, 이동/투사체/렌더/충돌/타겟팅에 래핑 좌표계를 적용했다.
- 레벨업 이벤트가 퀴즈 모달을 열고, 채점 결과에 따라 3개 또는 2개 스킬 선택지를 보여주도록 연결했다.
- 각성 가능 상태에서는 각성 보상이 첫 선택지에 우선 등장한다.
