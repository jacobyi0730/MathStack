# T-059 · 전투 타격감

## 요청

전투에 타격감이 거의 없다. 적이 죽거나 주인공이 데미지를 입었을 때, 보스가 스킬을 써서 국면이 바뀔 때 등 다양한 상황에서 타격감이 느껴지도록 처리한다.

## 문제

데미지 숫자(T-030)가 유일한 피드백이었다. 세 가지가 빠져 있었다.

1. **내 공격이 닿았는지 알 수 없다.** 적 300체가 뒤엉킨 화면에서 숫자는 서로를 가린다. 적은 맞고도 그대로 걸어온다.
2. **내가 언제 맞았는지 알 수 없다.** 체력 바가 줄어드는 것 말고는 아무 반응이 없다.
3. **보스가 무엇을 하는지 알 수 없다.** 보스 피격에는 데미지 숫자조차 뜨지 않았다.

## 완료 조건 (DoD)

- [x] 적 피격 시 흰 섬광과 밀림이 나타난다.
- [x] 적 처치 시 그 자리에 파편과 충격파 고리가 남는다.
- [x] 주인공 피격 시 화면 흔들림·히트스톱·붉은 비네트가 함께 나온다.
- [x] 보스 피격에 데미지 숫자가 뜨고, 보스 스킬·페이즈 전환·처치에 각기 다른 연출이 붙는다.
- [x] 데미지 숫자가 종류별로 색·크기·방향이 갈린다.
- [x] 접근성 "효과 강도 0%"에서 흔들림·히트스톱·전체 섬광이 전부 꺼진다.
- [x] 게임 루프에서 할당이 일어나지 않는다 (파편·고리 모두 고정 풀).
- [x] `npm run typecheck`, `npm run lint`, `npm run test`, `npm run build` 가 통과한다.

## 설계 결정

- **흔들림과 멈춤은 큰 사건에만.** 잡몹 처치에 주면 10분 내내 흔들려 정작 보스 스킬이 안 보인다. 잡몹은 파편만, 흔들림은 피격·보스·운석에만.
- **흔들림은 트라우마의 제곱**으로 화면을 민다. 선형이면 작은 타격이 보스 처치와 구분되지 않는다.
- **히트스톱 중에도 흔들림은 흐른다.** 멈춘 세계를 흔들리는 카메라가 비추는 것이 이 연출의 전부다. 같이 멈추면 그냥 얼어붙어 보인다.
- **붉은 비네트는 주인공 피격에만 쓴다.** 다른 곳에 한 번이라도 쓰면 그 순간 신호가 아니게 된다.
- **효과 강도 0%에서도 파편과 고리는 남긴다.** 그것은 연출이 아니라 "저기서 뭔가 일어났다"는 정보다.
