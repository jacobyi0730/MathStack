# T-058 · 보스전 모바일·성능·밸런스 검증

## 목적

새 보스 패턴이 재미있어도 모바일에서 피할 수 없거나 성능을 무너뜨리면 실패다. 세 보스의 가독성, 회피 가능성, 피해량, 성능을 한 번에 검증하고 튜닝한다.

## 범위

- [x] 세로 FHD 모바일 기준 보스전 화면 확인
- [x] 데스크톱 기준 보스 패턴 가독성 확인
- [x] `docs/30-기술/34-성능예산.md` — 최종보스 스트레스 측정 갱신
- [x] `docs/06-개선기록.md` — 최종 튜닝 기록
- [x] `tests/src/` — 회귀 테스트 보강

## 완료 기준

- [x] 터치 이동으로 모든 보스의 핵심 패턴을 회피할 수 있다.
- [x] 전조, 피해 영역, 탄막이 배경/무기 이펙트와 구분된다.
- [x] 피해량이 회복 아이템 빈도와 맞고, 1회 실수가 즉시 실패로 이어지지 않는다.
- [x] `npm run typecheck`, `npm run lint`, `npm run test`, `npm run build`가 통과한다.

## 결과

- 구현: `src/engine/stress.ts` — 스트레스 프리셋에 보스 위험 개체 상한(탄 96 + 장판·유성 24)과 페이즈별 시계 프라이밍 추가
- 테스트: `tests/src/stress.test.ts` — 위험 개체 상한 도달, `skipped` 0, 엔티티 총계, 전 풀 recycle 0
- 문서: `docs/30-기술/34-성능예산.md` §5·§6
- 검증:
  - 헤드리스 900프레임(최악 부하 재충전) — sim **avg 0.0574ms, p99 0.359ms**, 예산 16.6ms. 동시 엔티티 최대 **629**. 전 풀 recycle 0
  - 헤드리스 Chrome 151 + CDP, `?stress=1` 1280×720 — 경고 원·장판·보스 탄 렌더 확인, **JS 오류 0 · 네트워크 실패 0**
  - Vite 빌드 gzip **76.0KB** / 예산 100KB
- **남은 검증**: 실기기 모바일 터치 회피와 회복 아이템 빈도 대비 피해량은 사람이 직접 플레이해야 판단할 수 있다. 헤드리스로는 "피할 수 있게 배치됐는지"(장판 최소 거리, 안전각 존재)까지만 자동 검증한다.
