# T-058 · 보스전 모바일·성능·밸런스 검증

## 목적

새 보스 패턴이 재미있어도 모바일에서 피할 수 없거나 성능을 무너뜨리면 실패다. 세 보스의 가독성, 회피 가능성, 피해량, 성능을 한 번에 검증하고 튜닝한다.

## 범위

- [ ] 세로 FHD 모바일 기준 보스전 화면 확인
- [ ] 데스크톱 기준 보스 패턴 가독성 확인
- [ ] `docs/30-기술/34-성능예산.md` — 최종보스 스트레스 측정 갱신
- [ ] `docs/06-개선기록.md` — 최종 튜닝 기록
- [ ] `tests/src/` — 회귀 테스트 보강

## 완료 기준

- [ ] 터치 이동으로 모든 보스의 핵심 패턴을 회피할 수 있다.
- [ ] 전조, 피해 영역, 탄막이 배경/무기 이펙트와 구분된다.
- [ ] 피해량이 회복 아이템 빈도와 맞고, 1회 실수가 즉시 실패로 이어지지 않는다.
- [ ] `npm run typecheck`, `npm run lint`, `npm run test`, `npm run build`가 통과한다.
