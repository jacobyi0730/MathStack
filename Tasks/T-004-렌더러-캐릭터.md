# T-004 · 렌더러 & 캐릭터 스프라이트

## 목표

Canvas 2D 렌더러와 **원+눈** 캐릭터 그리기를 구현한다. 스프라이트 이미지 없이 코드로만 그린다.

## 캐릭터 규격 (기획서 §5.1)

| 파라미터 | 값 |
| --- | --- |
| 몸통 | 정원, 반지름 10~28px |
| 외곽선 | 2px, 몸통색 20% 어둡게 |
| 눈 | 흰 원 r=몸통r×0.25, 동공 r=흰자×0.5 |
| 시선 | 동공이 **이동 방향으로** 오프셋 (최대 흰자 r의 40%) |
| 그림자 | 타원, y+r×0.8, 투명도 20% |
| 피격 | 3프레임 흰색 플래시 + 넉백 |
| 사망 | 0.2초 확대 후 축소 소멸 + 파티클 6개 |

플레이어는 눈이 **크고 또렷하게**, 적은 작거나 흐리게. 한눈에 아군/적을 구분하기 위한 규칙이다.

## 범위

- [ ] `src/engine/renderer.ts` — 캔버스 초기화, 리사이즈, 배경 격자
- [ ] `src/engine/camera.ts` — 플레이어 추적, 화면 밖 **컬링**
- [ ] `src/entities/sprite.ts` — 원+눈 그리기 (색·반지름·눈 개수·장식 파라미터)
- [ ] `src/data/palette.ts` — 기획서 §5.3 팔레트
- [ ] 피격 플래시 / 사망 연출

## 성능 규칙

- **배치 렌더.** 같은 색·크기끼리 모아 그리고 `fillStyle` 변경 횟수를 최소화한다.
- **화면 밖 컬링.** 카메라 뷰포트 밖 오브젝트는 그리지 않는다.
- 렌더 함수 안에서 객체를 만들지 않는다.

## 완료 조건 (DoD)

- [ ] 플레이어 4종이 팔레트대로 그려진다
- [ ] 동공이 이동 방향을 따라간다
- [ ] 화면 밖 오브젝트가 컬링된다 (계측으로 확인)
- [ ] 500개를 그려도 렌더 구간이 4ms 이내
- [ ] `npm run lint` · `npm run test` 통과

## 주의

외부 이미지·CDN 폰트를 쓰지 않는다. 정적 배포이므로 모든 자산은 번들에 포함되어야 한다.
