# T-004 · 렌더러 & 캐릭터 스프라이트

## 목표

Canvas 2D 렌더러와 **원+눈** 캐릭터 그리기를 구현한다. 스프라이트 이미지 없이 코드로만 그린다.

## 캐릭터 규격 (기획서 §5.1)

| 파라미터 | 값 |
| --- | --- |
| 몸통 | 정원, 반지름 10~28px |
| 외곽선 | 2px, 몸통색 20% 어둡게 |
| 눈 | 흰 원 r=몸통r×0.25, 동공 r=흰자×0.5 |
| 시선 | 동공이 **이동 방향으로** 오프셋 (최대 흰자 r의 40%) |
| 그림자 | 타원, y+r×0.8, 투명도 20% |
| 피격 | 3프레임 흰색 플래시 + 넉백 |
| 사망 | 0.2초 확대 후 축소 소멸 + 파티클 6개 |

플레이어는 눈이 **크고 또렷하게**, 적은 작거나 흐리게. 한눈에 아군/적을 구분하기 위한 규칙이다.

### 구현 방식

- **배치 렌더** — 보이는 엔티티만 먼저 수집한 뒤 `paletteGroup + paletteIndex + radius` 조합별로 묶어 본체·외곽선을 그린다. `fillStyle` 변경이 배치 수만큼만 일어난다. 동공·심볼·장식은 별도 패스.
- **컬링** — `camera.ts` 의 `createCameraState`·`worldToScreen`·`isCircleVisible` 로 분리. 화면 밖 원형 스프라이트는 **수집 단계에서 제외**되므로 그리기 비용이 아예 들지 않는다.
- **보간** — `render(state, alpha)` 에서 플레이어 보간 위치를 기준으로 카메라를 잡는다.
- **테스트 가능하게 분리** — 동공 오프셋·눈/그림자 규격·심볼 위치를 `sprite.ts` 의 순수 계산으로 빼서 단위 테스트했다. 그리기 자체는 테스트하지 않는다.
