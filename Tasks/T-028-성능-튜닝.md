# T-028 · 성능 튜닝 & 스트레스 모드

## 목표

**적 300체 + 투사체 200개에서 프레임 16.6ms 이내**를 실측으로 달성하고, 그 상태를 지킬 계측 수단을 남긴다.

## 범위

- [ ] `src/engine/stress.ts` — 스트레스 모드 (`?stress=1`)
  - 적 300체 + 투사체 200개 즉시 스폰
  - 무기 6슬롯 각성 상태로 세팅
  - 프레임 타이머 오버레이 상시 표시
- [ ] 계측 항목: `frame / sim / collide / render` ms, `entities`, `pool alloc`
- [ ] 최종보스 구간 시나리오 프리셋 (최악 조건)
- [ ] 병목 제거
- [ ] `docs/30-기술/34-성능예산.md`에 측정 기록

## 예산

| 시나리오 | 기준 |
| --- | --- |
| 적 300체 + 투사체 200개 | 프레임 **16.6ms** |
| 최악 프레임 (p99) | 33ms |
| GC 일시정지 | 프레임당 0회 |
| 충돌 구간 | 6ms |
| 렌더 구간 | 4ms |
| `pool alloc` | **0** |

## 병목 점검 순서

프레임이 예산을 넘으면 **이 순서로** 의심한다. 대개 1~3에서 잡힌다.

1. 루프 안 할당 — `new`, 객체 리터럴, `map`/`filter`/스프레드
2. 오브젝트 풀 미사용
3. O(n²) 충돌 — 공간 해시 셀 크기 부적절 포함
4. 컬링 누락
5. 배치 미적용 — `fillStyle` 변경 횟수
6. 캔버스 상태 변경 과다 (`save`/`restore`)

## 주의

**스트레스 모드를 제거하지 않고 남긴다.** 이후 누가 적이나 무기를 추가할 때마다 `perf-check` 스킬이 이걸 쓴다. 한 번 튜닝하고 계측 수단을 지우면 다음 회귀를 잡을 방법이 없어진다.
