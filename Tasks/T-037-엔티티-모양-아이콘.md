# T-037. 엔티티 모양 체계와 아이콘

## 배경

화면 위의 **모든 것이 원 + 눈**이었다. 적도 원, 상자도 원, 즉시 발동 아이템도 원, 투사체도 원. 색만 달랐다. 그래서 적 무리 속에서 "이건 나를 쫓는 것 / 이건 내가 가서 먹는 것 / 이건 내가 쏜 것"이 갈리지 않았다.

특히 두 곳이 나빴다.

- **원소 램프(상자)** 가 눈 달린 원이라 적으로 보였다. 부수러 가야 할 것이 도망쳐야 할 것처럼 보였다.
- **황금 나선(부메랑)** 투사체가 원소 조각과 똑같은 원이었다. 무기가 무슨 일을 하는지 화면에서 읽히지 않았다.
- 철 결계·산소 파동처럼 **넓게 퍼지는 오라·파동**은 반지름 96~184짜리 불투명 원에 눈까지 달려 있어 화면을 통째로 가렸다.

## 범위

- `RenderableEntity` 에 `shape` 와 `icon` 을 추가하고 모양 체계 4종을 세움
  - `circle` 원 + 눈 — 플레이어, 적, 보스 (**눈은 살아 있는 것에만**)
  - `box` 둥근 사각 + 뚜껑선 + 세로 끈 — 원소 램프
  - `icon` 원 배지 + 이모지 — 즉시 발동 아이템, 투사체
  - `field` 반투명 채우기 + 밝은 테두리 — 오라, 파동
- 즉시 발동 아이템 6종에 기능이 읽히는 이모지 배정 (❤️ 🧲 💣 ⏱️ 🔥 🛡️)
- 무기 16종에 패턴이 읽히는 이모지 배정 (🏹 ⚡ 💠 🌊 ⚙️ 💥 🌀 ✨ / 각성 8종)
- 아이템과 무기가 같은 이모지를 쓰지 않도록 회귀 테스트 추가
- 이모지 크기를 14~40px 로 묶음 — 반지름 5짜리 수소 화살도 읽히고, 반지름 48짜리 마그네슘 폭탄도 화면을 안 덮는다
- 기록용 캔버스 대역으로 렌더러 테스트 신설 (기존에 렌더러 테스트가 없었다)

## 성능에서 조심한 것

아이콘 배지를 배치(batch)에서 빼면 **투사체 200개가 전부 개별 드로우콜**이 된다. 배지는 결국 원이므로 기존 원 배치 경로에 그대로 두고, 이모지 글자만 별도 패스로 얹었다. 배치에서 빠지는 것은 상자(≤6)와 장판(≤2)뿐이다.

캔버스에서 `font` 대입은 비싸다. 이모지 크기를 정수로 반올림하고 **직전 프레임과 크기가 같으면 대입을 건너뛴다.**

## 남겨 둔 것

산소 파동·철 결계와 그 각성형은 장판으로 그려지므로 배정한 아이콘이 화면에 나오지 않는다. 값은 지우지 않았다 — HUD와 스킬 선택 창에서 쓸 자리다.
