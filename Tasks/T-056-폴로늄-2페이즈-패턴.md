# T-056 · 폴로늄 2페이즈 패턴 구현

## 목적

두 번째 보스가 중반 난이도 상승을 맡도록 2페이즈 구조를 구현한다. 1페이즈는 순간이동과 분할 탄막, 2페이즈는 독성 장판과 더 촘촘한 분할 탄막을 추가한다.

## 범위

- [x] `src/data/bosses.ts` — 폴로늄 페이즈 임계값과 패턴 수치
- [x] `src/entities/boss.ts` 또는 후속 보스 패턴 시스템 — HP 45% 이하 2페이즈 전환
- [x] `tests/src/boss.test.ts` — 페이즈 전환, 순간이동, 분할 탄막, 장판 검증
- [x] 문서/개선 기록 동기화

## 완료 기준

- [x] HP 45% 이하에서 2페이즈로 전환되고 전환 신호가 1회 발생한다.
- [x] 1페이즈는 4방향 분할 탄막, 2페이즈는 6방향 분할 탄막과 경고 장판 3개를 사용한다.
- [x] 장판은 중앙을 완전히 막지 않고, 전조 후에만 피해를 준다.
- [x] 게이트와 보스 스트레스 테스트가 통과한다.

## 결과

- 구현: `src/data/bosses.ts`(`BOSS_PATTERNS.polonium` 2페이즈 배열), `src/entities/boss.ts`(HP 45% 전환·0.8초 정지), `src/systems/boss-patterns.ts`(분할 탄막·독성 장판)
- 테스트: `tests/src/boss.test.ts` — 45% 전환 1회, 1페이즈 4방향 / 2페이즈 6방향, 장판 3개, 결정적 순간이동 / `tests/src/boss-hazard.test.ts` — 분열 후 탄속 감소, 장판이 플레이어 발밑에 깔리지 않음
- 문서: `docs/03-전투확장.md` §9.3.4
- 설계 결정: 장판은 플레이어에게서 **최소 150px** 를 띄운다. 발밑에 깔리면 전조가 있어도 소용없어 "보고 비킨다"가 성립하지 않는다.
