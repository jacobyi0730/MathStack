# T-056 · 폴로늄 2페이즈 패턴 구현

## 목적

두 번째 보스가 중반 난이도 상승을 맡도록 2페이즈 구조를 구현한다. 1페이즈는 순간이동과 분할 탄막, 2페이즈는 독성 장판과 더 촘촘한 분할 탄막을 추가한다.

## 범위

- [ ] `src/data/bosses.ts` — 폴로늄 페이즈 임계값과 패턴 수치
- [ ] `src/entities/boss.ts` 또는 후속 보스 패턴 시스템 — HP 45% 이하 2페이즈 전환
- [ ] `tests/src/boss.test.ts` — 페이즈 전환, 순간이동, 분할 탄막, 장판 검증
- [ ] 문서/개선 기록 동기화

## 완료 기준

- [ ] HP 45% 이하에서 2페이즈로 전환되고 전환 신호가 1회 발생한다.
- [ ] 1페이즈는 4방향 분할 탄막, 2페이즈는 6방향 분할 탄막과 경고 장판 3개를 사용한다.
- [ ] 장판은 중앙을 완전히 막지 않고, 전조 후에만 피해를 준다.
- [ ] 게이트와 보스 스트레스 테스트가 통과한다.
