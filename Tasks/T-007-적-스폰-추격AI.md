# T-007 · 적 스폰 & 추격 AI

## 목표

스폰 시스템과 기본 AI 프레임워크를 만든다. 이 태스크에서는 **라돈 유령 1종**만 구현하고, 나머지 6종은 T-014에서 붙인다.

## 범위

- [ ] `src/entities/enemy.ts` — 오브젝트 풀 기반 적 엔티티
- [ ] `src/systems/spawn.ts` — 화면 밖 가장자리 링 스폰, 플레이어로부터 **최소 400px**
- [ ] `src/systems/enemy-ai.ts` — AI 디스패치. 이번엔 `chase`만
- [ ] `src/data/enemies.ts` — 라돈 유령 `radon` (Rn, 86번 / HP 20 / 속도 40 / 접촉피해 4 / 경험치 1)
- [ ] 적 데이터에 `element`·`atomicNumber` 필드 (도감·스프라이트 라벨이 쓴다)
- [ ] `src/data/waves.ts` — 시간대별 밀도 테이블

## 스폰 규칙 (기획서 §9.3)

```
밀도 = 기본 × (1 + 경과분 × 0.35)
HP   = 기본 × (1 + 경과분 × 0.18)
```

- 동시 존재 상한 **300체**. 상한 도달 시 **가장 먼 개체부터 소멸**
- 스폰 위치는 카메라 뷰포트 밖 링. 플레이어 눈앞에 튀어나오지 않는다

## AI 프레임워크

```ts
// enemy.ai 문자열로 분기. 새 종류는 add-enemy 스킬로 추가한다
const AI = { chase, charge, tank, split, ranged, flee };
```

이번 태스크에서는 `chase`(직선 추격)만 구현하되, **디스패치 구조는 6종을 받을 수 있게** 만든다.

## 완료 조건 (DoD)

- [ ] 적이 화면 밖에서 스폰되어 플레이어를 추격한다
- [ ] 시간이 지나면 밀도와 HP가 공식대로 증가한다
- [ ] 300체 상한이 지켜지고 초과 시 먼 개체가 정리된다
- [ ] 적 전량이 오브젝트 풀에서 나온다 (`pool alloc` = 0)
- [ ] `perf-check` — 300체에서 16.6ms 이내
- [ ] `npm run lint` · `npm run test` 통과
