# T-057 · 오가네손 3페이즈 패턴 구현

## 목적

최종보스가 세션의 클라이맥스가 되도록 3페이즈 패턴을 구현한다. 소환, 유성, 붕괴 장판, 돌진, 회전 탄막을 단계적으로 누적한다.

## 범위

- [x] `src/data/bosses.ts` — 오가네손 페이즈별 수치
- [x] `src/entities/boss.ts` 또는 후속 보스 패턴 시스템 — HP 66%/33% 페이즈 전환
- [x] `src/systems/spawn.ts` 또는 보스 소환 시스템 — 보스전 전용 소환수 상한
- [x] `tests/src/boss.test.ts`, `tests/src/stress.test.ts` — 3페이즈 패턴과 성능 검증
- [x] 문서/개선 기록 동기화

## 완료 기준

- [x] 66% 이하 2페이즈, 33% 이하 3페이즈 전환이 정확히 1회씩 발생한다.
- [x] 1페이즈는 소환+원형 탄막, 2페이즈는 유성+붕괴 장판, 3페이즈는 돌진+회전 탄막을 사용한다.
- [x] 소환수는 동시 8체 이하, 2페이즈 이후 6체 이하로 제한된다.
- [x] 최종보스 스트레스 프리셋에서 프레임 예산을 넘지 않는다.

## 결과

- 구현: `src/data/bosses.ts`(`BOSS_PATTERNS.oganesson` 3페이즈), `src/entities/boss.ts`(돌진 상태 기계 windup→dash→recover), `src/systems/boss-patterns.ts`(유성·붕괴 장판·소환), `src/systems/spawn.ts`(`spawnEnemyAt` 공개)
- 테스트: `tests/src/boss.test.ts` — 66%/33% 각 1회, 페이즈별 패턴, 돌진 3단계와 돌진 후 16발, 돌진 중 접촉 피해 완화 / `tests/src/boss-hazard.test.ts` — 후반 소환 상한 6체
- 문서: `docs/03-전투확장.md` §9.3.3·§9.3.4
- 설계 차이 둘:
  - 2페이즈 소환을 **회당 4체 → 3체**로 줄였다. 4체를 유지하면 상한 6체에 매번 부딪혀 소환이 절반은 무시된다 — "불렀는데 안 나온다"가 반복되면 패턴이 아니라 버그로 읽힌다.
  - **돌진 중 접촉 피해를 32 → 18 로 낮춘다.** 피할 수 있게 만든 패턴의 실패 벌이 가장 크면, 플레이어는 패턴을 배우는 대신 보스를 피해 다닌다.
