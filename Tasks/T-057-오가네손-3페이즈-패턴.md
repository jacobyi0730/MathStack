# T-057 · 오가네손 3페이즈 패턴 구현

## 목적

최종보스가 세션의 클라이맥스가 되도록 3페이즈 패턴을 구현한다. 소환, 유성, 붕괴 장판, 돌진, 회전 탄막을 단계적으로 누적한다.

## 범위

- [ ] `src/data/bosses.ts` — 오가네손 페이즈별 수치
- [ ] `src/entities/boss.ts` 또는 후속 보스 패턴 시스템 — HP 66%/33% 페이즈 전환
- [ ] `src/systems/spawn.ts` 또는 보스 소환 시스템 — 보스전 전용 소환수 상한
- [ ] `tests/src/boss.test.ts`, `tests/src/stress.test.ts` — 3페이즈 패턴과 성능 검증
- [ ] 문서/개선 기록 동기화

## 완료 기준

- [ ] 66% 이하 2페이즈, 33% 이하 3페이즈 전환이 정확히 1회씩 발생한다.
- [ ] 1페이즈는 소환+원형 탄막, 2페이즈는 유성+붕괴 장판, 3페이즈는 돌진+회전 탄막을 사용한다.
- [ ] 소환수는 동시 8체 이하, 2페이즈 이후 6체 이하로 제한된다.
- [ ] 최종보스 스트레스 프리셋에서 프레임 예산을 넘지 않는다.
