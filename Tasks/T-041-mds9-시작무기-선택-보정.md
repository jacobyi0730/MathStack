# T-041. mds/9 시작 무기 선택 보정

## 범위

- 시작 선택 카드가 패시브 특성이 아니라 공격 무기 정보를 보여주게 수정
- 악티늄·토륨·란타넘·세륨 선택 보너스를 중립화
- 시작 선택이 실제 `startingWeaponId` 공격 무기를 가리키는지 테스트 추가
- 전투 확장 문서와 개선 기록 갱신

## 결과

- 시작 화면의 마지막 단계가 `시작 무기 선택`으로 표시된다.
- 각 선택지는 시작 공격명, 공격 방식, 피해량, 쿨타임을 보여준다.
- 선택 원소는 이동속도·체력·투사체 수 같은 패시브 보너스를 주지 않는다.
