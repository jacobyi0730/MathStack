# T-015 · 보스 3종 & 웨이브 타임라인

## 목표

10분 세션의 웨이브 타임라인을 완성하고 보스 3종을 구현한다. **세션의 뼈대가 여기서 완성된다.**

## 타임라인 (기획서 §4)

| 시각 | 이벤트 | 밀도 |
| --- | --- | --- |
| 0:00~1:00 | 튜토리얼 — 라돈 유령만 소수 | 낮음 |
| 1:00~2:30 | 소듐 돌격체 합류 | 보통 |
| 2:30~3:00 | 밀집 웨이브 | 높음 |
| **3:00** | **중간보스 1 — 테크네튬 복제자** (Tc, 43 / HP 800) | — |
| 3:00~5:30 | 납 방벽 · 우라늄 분열체 혼합 | 보통↑ |
| **6:00** | **중간보스 2 — 폴로늄 분할자** (Po, 84 / HP 1,800) | — |
| 6:00~8:00 | 전 종류 혼합, 밀도 급상승 | 매우 높음 |
| 8:00~9:00 | **초월 수련** (T-025에서 구현) | — |
| 9:00~10:00 | **최종보스 — 오가네손 · 붕괴의 왕** (Og, 118 / HP 6,000) + 잡몹 | 최대 |
| 10:00 | 결과 화면 | — |

**보스 원자번호가 43 → 84 → 118로 오른다.** 주기율표를 거슬러 올라가 마지막 칸에 닿는 구조이며, 그것이 곧 진행도다.

## 보스 패턴

| 보스 | 번호 | 근거 | 패턴 |
| --- | --- | --- | --- |
| 테크네튬 복제자 (Tc) | 43 | 소수. **최초의 인공 원소** — 만들어진 존재라서 자기를 복제한다 | 3초마다 분신 2체 소환. 느리지만 접촉 피해 큼 |
| 폴로늄 분할자 (Po) | 84 | **고도합성수** — 약수 12개, 잘 나뉘는 수 | 원형 탄막을 4방향 분할 발사. 순간이동 |
| 오가네손 · 붕괴의 왕 (Og) | 118 | **주기율표의 마지막 칸.** 반감기 1초 미만 | **3페이즈** — 잡몹 소환 → 광역 장판 → 추격 돌진 |

- [ ] 승리 조건: 10분 생존 + 오가네손 처치 / 패배 조건: 체력 0

## 완료 조건 (DoD)

- [ ] 타임라인이 명세대로 진행된다 (시각별 확인)
- [ ] 보스 3종이 지정 시각에 등장하고 패턴이 동작한다
- [ ] 오가네손 3페이즈 전환이 HP 기준으로 일어난다
- [ ] 원소 캡슐이 무기/보조를 레벨업시키고 **문제를 출제하지 않는다**
- [ ] 10분 완주와 패배 양쪽 모두 결과 화면으로 간다
- [ ] `perf-check` — 최종보스 + 잡몹 최대 밀도에서 16.6ms 이내
- [ ] `npm run lint` · `npm run test` 통과

## 주의

**최종보스 구간이 성능 최악 시나리오다.** 잡몹 300체 + 보스 탄막 + 각성 무기 투사체가 겹친다. 여기서 프레임이 무너지면 게임의 클라이맥스가 망가진다.
