# T-043. mds/11 아이템·보상 몬스터·UI·밸런스 보정

## 범위

- HUD 무기·보조무기 슬롯을 원소 기호 대신 이름으로 표시
- 슬롯 레벨 표기에서 `^` 제거
- 무기·보조무기 6칸이 가득 차면 새 장비 후보 제외
- 넵투늄 조류 피해·범위·쿨타임 밸런스 조정
- 램프 자동 스폰 비활성화
- 아이오딘/이리듐 보상 몬스터 흐름 개편
- 보상 아이템 등장 시 화면 상단 큰 알림 표시
- 특별 몬스터 스폰 비중 상향

## 결과

- 아이오딘 방울은 처치만으로 회복 아이템을 떨어뜨린다.
- 이리듐 유성은 처치 후 문제를 풀고 정답일 때 자석 또는 폭탄을 떨어뜨린다.
- 이리듐 유성이 폭탄에 죽어도 보상 문제 대기열에 들어간다.
