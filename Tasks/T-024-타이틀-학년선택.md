# T-024 · 타이틀 & 학년/캐릭터 선택

## 목표

게임 진입 흐름을 만든다. **학년·학기 선택이 문항 뱅크 로드를 결정**하므로 출제 시스템의 입구다.

## 화면 흐름 (기획서 §14.1)

```
타이틀 → 학년/학기 선택 → 캐릭터 선택 → (용사 이름 입력) → 게임 → 결과
```

## 범위

- [ ] `src/ui/title.ts` — 타이틀 화면
- [ ] `src/ui/grade-select.ts` — 학년 3~6, 학기 1~2 선택
- [ ] `src/ui/character-select.ts` — 플레이어 4종 (기획서 §5.2)
- [ ] 용사 이름 입력 (선택, 기본값 제공)
- [ ] 선택값을 `localStorage`에 저장 → 다음 판에 기본값으로
- [ ] 학년 확정 시 해당 뱅크 로드 (T-020의 loader 호출)

## 학기 선택의 의미

**기본값은 "현재 학기까지".** 3학년 1학기 학생에게 2학기 분수 문항을 내지 않는다. 설정에서 "전 학년 범위"로 확장할 수 있게 한다.

| 옵션 | 출제 범위 |
| --- | --- |
| 1학기 | `semester == 1` |
| 2학기 (기본) | `semester <= 2` |
| 전 범위 | 해당 학년 전체 |

## 로딩 처리

뱅크는 gzip 45~120KB다. 학교 와이파이에서 느릴 수 있으므로 **로딩 표시를 넣는다.** 로드 실패 시 재시도 버튼을 보여준다 — 정적 파일이라 대개 새로고침으로 해결된다.

## 완료 조건 (DoD)

- [ ] 타이틀 → 게임까지 흐름이 끊기지 않는다
- [ ] 학년 4개 × 학기 옵션이 전부 동작한다
- [ ] 선택한 학년의 뱅크만 로드된다 (네트워크 탭으로 확인)
- [ ] 로딩 중 표시가 나오고, 실패 시 재시도할 수 있다
- [ ] 이전 선택이 `localStorage`에서 복원된다
- [ ] 캐릭터 4종 특성이 실제로 적용된다
- [ ] `npm run lint` · `npm run test` 통과

## 주의

학년 선택 화면은 **아이가 매번 보는 첫 화면**이다. 학년 버튼을 크게 만들고, 잘못 고르면 게임 중에도 바꿀 수 있는 경로를 남긴다.
