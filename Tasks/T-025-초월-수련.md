# T-025 · 초월 수련 (8~9분 구간)

## 목표

**게임에서 수학이 가장 크게 보상받는 순간**을 만든다. 문제를 성실히 풀 동기를 여기서 만든다.

## 동작 (기획서 §4)

```
8:00  전투 완전 중단, 화면 전환
      → 난이도 4~5 문항 3개 연속 출제
      → 3문제 전부 정답 시 각성 무기 1개 즉시 부여
9:00  전투 재개 → 최종보스 구간
```

## 범위

- [ ] `src/systems/trial.ts` — 초월 수련 상태 전환
- [ ] 전투 완전 중단 — 적 소멸 또는 정지, 스폰 중단
- [ ] 난이도 **4~5 고정** 3문항 연속 출제
- [ ] 전용 연출 — 배경 전환, "초월 수련" 타이틀
- [ ] 보상 판정:

| 정답 수 | 보상 |
| --- | --- |
| 3 / 3 | **각성 무기 1개 즉시 부여** |
| 2 / 3 | 무기·패시브 각 1레벨 |
| 1 / 3 | 무기 1레벨 |
| 0 / 3 | 체력 전체 회복 (빈손으로 보내지 않는다) |

## 재도전 규칙

일반 레벨업과 **동일하게 재도전 1회를 허용**한다. 여기서만 처벌을 강화하면 §3 설계 원칙 3("오답은 처벌이 아니라 학습이다")을 뒤집는 것이 된다.

단, 재도전으로 맞힌 문항은 **정답 수에는 포함하되** 결과 화면 정답률에는 1차 정답만 집계한다.

## 각성 무기 선택

3/3 달성 시 부여할 각성 무기는 **플레이어가 보유한 무기 중 가장 레벨이 높은 것**의 각성형으로 한다. 짝꿍 패시브가 없어도 이때만은 예외로 부여한다 — 보상의 크기가 이 구간의 존재 이유다.

## 완료 조건 (DoD)

- [ ] 8:00에 전투가 멈추고 초월 수련이 시작된다
- [ ] 난이도 4~5 문항 3개가 연속 출제된다
- [ ] 정답 수에 따라 보상이 정확히 갈린다
- [ ] 3/3 달성 시 각성 무기가 실제로 부여되고 동작한다
- [ ] 9:00에 전투가 재개되고 최종보스 구간으로 이어진다
- [ ] 0/3이어도 빈손으로 끝나지 않는다
- [ ] `npm run lint` · `npm run test` 통과

## 주의

**뱅크에 난이도 4~5 문항이 부족하면 이 구간이 성립하지 않는다.** T-019에서 난이도 4·5를 각 15% 이상 확보했는지 먼저 확인한다. 부족하면 이 태스크를 시작하기 전에 문항을 채운다.
