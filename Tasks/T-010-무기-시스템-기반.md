# T-010 · 무기 시스템 기반 + 1종

## 목표

자동 공격 프레임워크를 만들고 **수소 화살 1종**을 구현한다. 나머지 7종은 T-011에서 붙는다.

## 범위

- [ ] `src/systems/weapons.ts` — 쿨타임 관리, 발사 패턴 디스패치
- [ ] `src/entities/projectile.ts` — 풀 기반 투사체
- [ ] `src/data/weapons.ts` — 수소 화살 `hydrogen_arrow` (H, 1번 / 데미지 10 / 쿨타임 1.2s)
- [ ] 무기 데이터에 `element`·`atomicNumber` 필드 (도감·툴팁이 쓴다)
- [ ] 무기 슬롯 6개, 무기별 독립 레벨 1~5
- [ ] 레벨업 효과: **Lv당 데미지 +20%, Lv3에서 투사체/범위 +1단계, Lv5에서 각성 자격**
- [ ] 가장 가까운 적 조준 (공간 해시 활용)

## 패턴 디스패치 구조

```ts
const PATTERNS = {
  projectile, pierce, orbit, wave, aura, bomb, boomerang, spread,
};
```

이번엔 `projectile`만 구현하되, **8종을 받을 수 있는 구조**로 만든다.

## 성능 규칙

- **투사체는 반드시 풀에서 꺼낸다.** 무기는 초당 수십 발을 만든다. 여기서 할당하면 프레임이 무너진다
- 조준 대상 탐색에 전수 비교 금지 — 공간 해시 `queryNearby` 사용
- 화면 밖으로 나간 투사체는 즉시 풀로 반환

## 완료 조건 (DoD)

- [ ] 플레이어가 가만히 있어도 자동으로 공격한다
- [ ] 가장 가까운 적을 조준한다
- [ ] 무기 레벨 1~5 성장이 규칙대로 적용된다
- [ ] 투사체 200개 동시 존재에서 `pool alloc` = 0
- [ ] 수치가 문서(기획서 §6)와 `src/data/weapons.ts`에서 일치한다
- [ ] `npm run lint` · `npm run test` 통과

## 주의

플레이어 공격 입력을 만들지 않는다. 모든 무기는 쿨타임으로만 발동한다.
