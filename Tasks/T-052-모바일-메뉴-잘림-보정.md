# T-052. 모바일 메뉴 잘림 보정

## 요청

모바일에서 실행하면 학년 선택 등 메뉴가 브라우저 UI에 가려 잘리고 진행이 안 된다. 전체적으로 UI를 확인하고 보정한다.

## 완료 조건 (DoD)

- [x] 타이틀 플로우 루트가 모바일 실제 뷰포트 기준으로 자체 스크롤된다.
- [x] 학년/범위 선택 화면이 세로 모바일에서 진행 버튼까지 도달 가능하다.
- [x] 캐릭터/시작 무기 선택 화면이 세로 모바일에서 시작 버튼까지 도달 가능하다.
- [x] 설정과 결과 화면도 긴 콘텐츠가 화면 밖으로 잘리지 않고 스크롤된다.
- [x] 메뉴 카드와 선택 버튼 높이를 모바일에서 더 조밀하게 조정했다.
- [x] `npm run typecheck`, `npm run lint`, `npm run test`, `npm run build` 가 통과한다.
