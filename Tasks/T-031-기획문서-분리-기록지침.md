# T-031. 기획 문서 분리 & 기록 지침

## 배경

기존 기획서는 하나의 큰 문서로 모든 결정을 담고 있어 개선 사항과 세부 시스템 변경을 추적하기 어렵다. 앞으로 기능 개선, 밸런스 조정, 기획 추가가 발생하면 구현과 함께 기획 문서, Task, TodoList에 기록을 남기는 규칙이 필요하다.

## 범위

- AGENTS.md 절대 규칙과 작업 절차에 변경 기록 원칙 추가
- `docs/MathStack기획서.md`를 기획 허브로 정리
- 기반, 게임코어, 전투확장, 수학시스템, 세션 및 운영, 개선 기록 문서 생성
- AGENTS.md 문서 인덱스에 신규 문서 등록
- Tasks/README.md와 TodoList.md에 T-031 기록 추가

## 결과

- `docs/01-기반.md`
- `docs/02-게임코어.md`

- `docs/06-개선기록.md`
