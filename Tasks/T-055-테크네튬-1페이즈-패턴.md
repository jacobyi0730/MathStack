# T-055 · 테크네튬 1페이즈 패턴 구현

## 목적

첫 보스가 보스 패턴의 튜토리얼 역할을 하도록, 기존 분신 패턴에 느린 원형 탄막을 추가한다. 페이즈는 1개만 유지한다.

## 범위

- [ ] `src/data/bosses.ts` — 테크네튬 패턴 수치와 설명 보정
- [ ] `src/entities/boss.ts` 또는 후속 보스 패턴 시스템 — 분신 + 원형 탄막 신호
- [ ] `tests/src/boss.test.ts` — 테크네튬이 1페이즈만 유지하고 탄막 신호를 내는지 검증
- [ ] 문서/개선 기록 동기화

## 완료 기준

- [ ] 3:00 보스는 HP와 무관하게 1페이즈만 가진다.
- [ ] 4.5초마다 8발 원형 탄막을 발사하고, 안전각이 남는다.
- [ ] 모바일 터치 이동으로 회피 가능한 속도와 밀도다.
- [ ] 게이트와 보스 스트레스 테스트가 통과한다.
