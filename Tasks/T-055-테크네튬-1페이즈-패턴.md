# T-055 · 테크네튬 1페이즈 패턴 구현

## 목적

첫 보스가 보스 패턴의 튜토리얼 역할을 하도록, 기존 분신 패턴에 느린 원형 탄막을 추가한다. 페이즈는 1개만 유지한다.

## 범위

- [x] `src/data/bosses.ts` — 테크네튬 패턴 수치와 설명 보정
- [x] `src/entities/boss.ts` 또는 후속 보스 패턴 시스템 — 분신 + 원형 탄막 신호
- [x] `tests/src/boss.test.ts` — 테크네튬이 1페이즈만 유지하고 탄막 신호를 내는지 검증
- [x] 문서/개선 기록 동기화

## 완료 기준

- [x] 3:00 보스는 HP와 무관하게 1페이즈만 가진다.
- [x] 4.5초마다 8발 원형 탄막을 발사하고, 안전각이 남는다.
- [x] 모바일 터치 이동으로 회피 가능한 속도와 밀도다.
- [x] 게이트와 보스 스트레스 테스트가 통과한다.

## 결과

- 구현: `src/data/bosses.ts`(`BOSS_PATTERNS.technetium`), `src/entities/boss.ts`(신호 시계), `src/systems/boss-patterns.ts`(원형 탄막·분신)
- 테스트: `tests/src/boss.test.ts` — 3.2초 분신 2체·4.5초 8발, 페이즈 배열 길이 1, 탄속 하한 / `tests/src/boss-hazard.test.ts` — 8칸 중 7발(안전각 한 칸)
- 문서: `docs/03-전투확장.md` §9.3.4
- 설계 차이: "큰 안전각"을 각도 확대가 아니라 **균등 배치에서 한 칸 비우기**로 구현했다. 각도만 넓히면 어디가 안전한지 안 보인다. 비는 칸은 발사마다 돌아가므로 한 자리에 서서 버틸 수는 없다.
