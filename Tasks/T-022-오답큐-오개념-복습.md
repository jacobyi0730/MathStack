# T-022 · 오답 큐 & 오개념 복습

## 목표

틀린 유형을 나중에 다시 내서 **아이가 실제로 배웠는지**를 만든다. 기획서 §17이 정의한 **"오개념 재출제 시 정답 전환율"** 이 이 게임의 진짜 교육 지표이며, 그 지표를 만드는 기능이다.

## 동작

```
오답 확정 (재도전도 실패)
   → misconceptionTag를 재출제 큐에 등록
   → 레벨 10 이상에서 큐가 비어있지 않으면 우선 출제
   → 같은 태그의 다른 문항을 낸다 (같은 문항 재출제 아님)
```

## 범위

- [ ] `src/quiz/review-queue.ts` — 오개념 태그 큐
- [ ] 같은 태그를 **2회 이상** 틀리면 우선순위 상승
- [ ] 복습 출제 시 **같은 문항이 아니라 같은 태그의 다른 문항**을 고른다
- [ ] 복습 문항은 난이도를 **1단계 낮춰서** 낸다 (성공 경험을 먼저 준다)
- [ ] 복습 정답 시 큐에서 제거, 오답 시 유지
- [ ] 세션 종료 시 태그별 통계 집계 (T-026 결과 화면용)

## 전환율 계측

```ts
// 결과 화면과 localStorage에 남길 값
{
  reviewed: 4,          // 복습 출제된 오개념 수
  converted: 3,         // 복습에서 맞힌 수
  conversionRate: 0.75, // 목표 50% 이상
}
```

## 태그 예시 (기획서 §12.2)

`decimal_alignment`, `fraction_denominator_add`, `borrow_omission`, `remainder_ignore`, `lcm_gcd_swap`, `area_perimeter_swap`, `ratio_inverse`, `circle_radius_diameter`

## 완료 조건 (DoD)

- [ ] 오답 확정 시 태그가 큐에 등록된다
- [ ] 레벨 10 이후 복습 문항이 실제로 나온다
- [ ] 복습 문항이 **같은 문항이 아니라 같은 태그의 다른 문항**이다
- [ ] 복습 문항 난이도가 1단계 낮다
- [ ] 전환율이 세션 종료 시 집계된다
- [ ] 시뮬레이션 테스트에서 전환율이 계산 가능하다
- [ ] `npm run lint` · `npm run test` 통과

## 주의

같은 태그의 다른 문항이 뱅크에 없으면 복습이 성립하지 않는다. **T-019에서 태그당 최소 3문항**을 확보했는지 확인한다. 없으면 난이도를 낮춘 같은 문항이라도 내되, 그 사실을 로그로 남긴다.
