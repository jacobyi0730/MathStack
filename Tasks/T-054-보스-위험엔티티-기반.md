# T-054 · 보스 탄막·장판 위험 엔티티 기반

## 목적

보스가 실제로 총알, 유성, 장판, 돌진 피해를 만들 수 있도록 런타임 기반을 추가한다. 기존 무기 투사체와 분리해 적 공격용 위험 엔티티 풀을 두고, 게임 루프에서 할당 없이 갱신한다.

## 범위

- [x] `src/entities/` — 보스 탄막/장판 엔티티와 풀
- [x] `src/systems/` — 보스 위험 엔티티 갱신, 플레이어 충돌, 피해 적용
- [x] `src/engine/state.ts` — 풀과 렌더 엔티티 연결
- [x] `src/engine/renderer.ts` — 경고 원, 장판, 보스 탄 렌더링
- [x] `tests/src/` — 풀 재사용, 충돌, 경고→발동 상태 테스트

## 설계 기준

- `boss_bullet` 96개, `boss_hazard` 24개를 v1 상한으로 둔다.
- 경고 상태와 피해 상태를 분리한다. 경고 중에는 피해가 없다.
- 풀 상한에 도달하면 새 위험 엔티티 생성을 건너뛴다.
- 게임 루프에서 배열·객체 할당과 `fetch`를 하지 않는다.

## 완료 기준

- [x] 보스 탄과 장판이 렌더링되고 플레이어에게 피해를 준다.
- [x] 경고 시간이 있는 패턴은 경고 중 피해가 없고, 발동 후 피해가 들어간다.
- [x] 스트레스 테스트에서 할당 없이 예산 안에 들어온다.
- [x] `npm run typecheck`, `npm run lint`, `npm run test`, `npm run build`가 통과한다.

## 결과

- 구현: `src/entities/hazard.ts`(엔티티·색), `src/systems/boss-hazard.ts`(풀·이동·분열·충돌), `src/engine/state.ts`, `src/engine/renderer.ts`(장판·탄 전용 패스), `src/engine/stress.ts`
- 테스트: `tests/src/boss-hazard.test.ts` — 풀 상한과 무할당, 전조 중 무피해, 전조 종료 후 피해, 유성 착탄·소멸, 탄 소비, 분열
- 문서: `docs/03-전투확장.md` §9.3.4, `docs/30-기술/34-성능예산.md` §5·§6
- 검증: `npm run typecheck`, `npm run lint`, `npm run test`(323개), `npm run build` 통과. 헤드리스 900프레임 sim avg 0.0574ms, 전 풀 recycle 0
- 설계 결정 둘:
  - **공간 해시를 쓰지 않는다.** 충돌 상대가 플레이어 하나뿐이라 위험 개체 120개를 전수 비교해도 프레임당 120회고, 해시를 세우는 비용이 그보다 크다.
  - **엔티티 목록에 넣지 않고 전용 렌더 패스를 둔다.** 경고 원의 채워지는 안쪽 원, 발동 순간의 색 전환은 팔레트 기반 스프라이트 경로로 표현할 수 없다. 장판은 엔티티 아래, 탄은 엔티티 위에 그린다 — 적 뒤에 숨은 탄은 피할 수 없다.
