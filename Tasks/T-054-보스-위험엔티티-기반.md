# T-054 · 보스 탄막·장판 위험 엔티티 기반

## 목적

보스가 실제로 총알, 유성, 장판, 돌진 피해를 만들 수 있도록 런타임 기반을 추가한다. 기존 무기 투사체와 분리해 적 공격용 위험 엔티티 풀을 두고, 게임 루프에서 할당 없이 갱신한다.

## 범위

- [ ] `src/entities/` — 보스 탄막/장판 엔티티와 풀
- [ ] `src/systems/` — 보스 위험 엔티티 갱신, 플레이어 충돌, 피해 적용
- [ ] `src/engine/state.ts` — 풀과 렌더 엔티티 연결
- [ ] `src/engine/renderer.ts` — 경고 원, 장판, 보스 탄 렌더링
- [ ] `tests/src/` — 풀 재사용, 충돌, 경고→발동 상태 테스트

## 설계 기준

- `boss_bullet` 96개, `boss_hazard` 24개를 v1 상한으로 둔다.
- 경고 상태와 피해 상태를 분리한다. 경고 중에는 피해가 없다.
- 풀 상한에 도달하면 새 위험 엔티티 생성을 건너뛴다.
- 게임 루프에서 배열·객체 할당과 `fetch`를 하지 않는다.

## 완료 기준

- [ ] 보스 탄과 장판이 렌더링되고 플레이어에게 피해를 준다.
- [ ] 경고 시간이 있는 패턴은 경고 중 피해가 없고, 발동 후 피해가 들어간다.
- [ ] 스트레스 테스트에서 할당 없이 예산 안에 들어온다.
- [ ] `npm run typecheck`, `npm run lint`, `npm run test`, `npm run build`가 통과한다.
