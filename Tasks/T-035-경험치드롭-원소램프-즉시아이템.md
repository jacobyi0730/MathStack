# T-035. 경험치 드롭·원소 램프·즉시 발동 아이템

## 배경

경험치가 적을 처치하는 순간 곧바로 들어왔다. 내부적으로는 픽업을 만들긴 했으나 **플레이어 위치에** 생성해 사실상 즉시 획득이었고, 그 결과 "안전한 구석에서 버티기"가 최적해가 되어 이동이 판단이 되지 않았다.

또한 필드에 파괴 가능한 오브젝트가 없어, 뱀파이어 서바이버의 촛대처럼 **전투 밖에서 보상을 캐는 축**이 통째로 빠져 있었다. 자석·폭탄 같은 즉시 발동 아이템은 `resolveEnemyReward`가 `'magnet' | 'bomb'` 을 돌려주기만 하고 아무도 소비하지 않는 죽은 경로였다.

## 범위

- 적 처치 보상을 **죽은 자리**에 떨어뜨리고, 주워야 발동하도록 변경 (경험치·회복 모두)
- 적 한 마리에 조각 하나. 경험치 양에 따라 겉모습만 3단계로 변한다
- **원소 램프** 4종(네온·아르곤·크립톤·제논) 추가 — 체력 1, 12초 주기, 동시 6개 상한
- 램프 파괴 시 **즉시 발동 아이템** 6종 드롭. 행운(luck)이 높을수록 희귀한 쪽에 걸린다
- 즉시 발동 아이템: 아이오딘 방울(회복), 네오디뮴 자석(조각 일괄 회수), 이리듐 운석(광역 피해), 세슘 시계(적 정지), 인 점화(쿨다운 감소), 금 보호막(무적)
- 아이템·상자 전용 팔레트 그룹(`paletteGroup 2`) 추가 — 적·플레이어와 색으로 먼저 구분되어야 한다
- 쓰이지 않게 된 `combat.pendingXp` 경유 경로 제거
- 기획 문서·성능 기록·작업 보드 갱신

## 참고한 레퍼런스

즉시 발동 아이템 목록은 뱀파이어 서바이버의 촛대 드롭(Floor Chicken / Attractorb / Rosary / Orologion / Nduja Fritta / Barrier)과 수학 서바이버의 전체 자석·전체 폭탄에서 가져왔다. 이름은 **원소 × 원자번호** 규칙(AGENTS §2 규칙 7)에 맞춰 다시 붙였다.

## DoD

- [x] 적을 처치하면 죽은 자리에 양성자 조각이 떨어지고, 주워야 경험치가 오른다.
- [x] 아이오딘 방울 처치 시 회복이 즉시 적용되지 않고 픽업으로 떨어진다.
- [x] 원소 램프가 주기적으로 등장하고, 플레이어 접촉 또는 투사체 명중 한 번에 깨진다.
- [x] 램프가 깨지면 즉시 발동 아이템이 떨어지고, 주우면 그 자리에서 발동한다.
- [x] 세슘 시계 발동 중 적과 보스가 멈추고, 인 점화 중 무기 쿨다운이 절반이 된다.
- [x] 적 300 + 투사체 185 + 조각 300 + 램프 6 시나리오에서 프레임 예산을 지킨다 (avg 0.0593ms).

> T-043 이후 램프 자동 스폰은 꺼졌다. 즉시 발동 아이템은 보상 몬스터를 통해 얻는 흐름이 정본이다.
- [x] 모든 풀의 recycle 이 0이다.
- [x] `test` · `typecheck` · `lint` · `build` 게이트를 통과한다.
