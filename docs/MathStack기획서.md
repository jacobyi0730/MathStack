## 변경 원칙

기능 개선, 기획 추가, 밸런스 변경은 코드만 고치지 않는다.

1. 해당 세부 기획 문서에 정본을 반영한다.
2. `Tasks/T-XXX-*.md`에 작업 범위와 DoD를 남긴다.
3. `TodoList.md`에 완료 상태와 배정 이력을 기록한다.
4. 피드백성 개선이면 [06-개선기록.md](06-개선기록.md)에 한 줄을 추가한다.
