# 43. 기여 규칙

> 문서를 어떻게 쓰고, 무엇을 커밋하고, 언제 "끝났다"고 말하는가.

## 1. 문서 작성

### 1.1 파일명

`NN-한글이름.md` 형식. **공백 대신 하이픈**을 쓴다 (`12-에이전트-적명세.md`).
번호대는 폴더 구분을 따른다 — 10 게임디자인 / 20 수학커리큘럼 / 30 기술 / 40 운영.

기획서 `MathStack기획서.md`만 예외다. 원본 요청이 경로를 명시했다.

### 1.2 프런트매터 (모든 `docs/` 문서 필수)

```markdown
---
title: 스킬·무기 명세
status: draft        # draft | review | stable
owner: 기획          # 기획 | 기술 | 수학
updated: 2026-08-20
related: [11-코어루프, 15-성장곡선]
---
```

### 1.3 본문 규칙

- **수치는 표로.** 밸런스·커리큘럼 수치를 산문에 묻어두지 않는다. 표는 코드/데이터로 옮기기 쉬워야 한다.
- **결정에는 근거를 한 줄 붙인다.** "쿨타임 3초" 뒤에 왜 3초인지.
- **코드에 들어갈 값은 문서가 정본이다.** 문서와 `src/data/`가 다르면 문서를 고치고 데이터를 맞춘다.
- 미결정은 `TBD:`로 표기하고 방치하지 않는다.
- **기획서가 상위 정본이다.** 하위 문서와 충돌하면 기획서를 기준으로 하위를 고친다. 기획서를 바꿔야 한다면 사용자에게 먼저 알린다.

### 1.4 인덱스 등록 ★

**AGENTS.md 문서 인덱스에 없는 문서는 없는 문서다.** 파일 생성과 인덱스 등록은 한 세트이며, `new-doc` 스킬이 그 순서를 강제한다.

내용이 비어 있으면 ✅를 붙이지 않는다. 껍데기 문서를 완료로 표시하는 것이 인덱스를 못 믿게 만드는 가장 빠른 길이다.

### 1.5 카탈로그 항목 템플릿

적·무기 카탈로그의 각 항목은 아래 필드를 **모두** 채운다. 빈 칸은 `TBD`.

```markdown
### E-08 프랑슘 유도체 (Fr)

| 필드 | 값 |
| --- | --- |
| id | `francium` |
| 원소 / 원자번호 | Fr / 87 |
| 수학적 근거 | 87 = 3 × 29. 가장 불안정한 자연 원소 — 22분이면 사라진다 |
| 등장 | 5:00~ |
| HP / 이동속도 / 접촉피해 | 70 / 30 / 5 |
| AI | 사거리 200 유지, 3초마다 유도탄 1발 |
| 드롭 | 양성자 조각 5 |
| 스프라이트 | 원 r=16, 눈 1개, `#7E57C2`, 방사선 표식 |
| 근거 | 중반에 "거리를 좁혀야 하는" 압박을 만드는 유일한 유도형 |
```

**`수학적 근거`와 `근거` 칸이 핵심이다.** 원자번호에서 수학적 의미를 못 찾거나, 이 개체가 플레이어에게 무엇을 강요하는지 한 줄로 못 쓰면 그 항목은 필요 없다.

## 2. Git

### 2.1 브랜치

`feat/`, `fix/`, `docs/`, `balance/`, `chore/` + 짧은 설명 (`feat/enemy-spawner`).

### 2.2 커밋 메시지

**Conventional Commits**, 제목은 한국어.

```
feat(enemy): 돌진형 적 소듐 돌격체 추가
docs(curriculum): 5학년 약분·통분 성취기준 매핑
balance(weapon): 황금 나선 쿨타임 3.0초 → 2.4초
chore(build): validate:bank를 Netlify 빌드 명령에 추가
```

### 2.3 원자성

- **문서와 코드가 함께 바뀌는 변경은 한 커밋으로 묶는다.** 밸런스 수치만 바꾸고 문서를 안 고친 커밋은 반려.
- 적·무기 추가는 문서·데이터·코드 세 곳이 한 커밋에 들어간다 (`add-enemy`·`add-weapon` 스킬이 순서를 강제한다).

### 2.4 커밋하지 않는 것

`.gitignore`가 막지만, 원칙을 알아둔다.

| | 이유 |
| --- | --- |
| `public/data/` | 생성물. `content/`에서 다시 구우면 된다 |
| `dist/`, `node_modules/` | 생성물·의존성 |
| `.claude/settings.local.json` | 개인 로컬 설정 |
| `.env*` | 비밀값 |

`.claude/agents/`·`.claude/skills/`·`.claude/settings.json`은 **팀 자산이므로 커밋한다.**

## 3. 작업 완료 기준

태스크를 끝냈다고 선언하기 전에 **`task-close` 스킬**을 거친다. DoD 확인·보드 동기화·후속 태스크 해제가 한 세트다.

공통 게이트:

```powershell
npm run typecheck
npm run lint
npm run test
npm run build:bank ; if ($?) { npm run validate:bank }
npm run build
```

| 건드린 것 | 추가 게이트 |
| --- | --- |
| 게임 루프·충돌·렌더 | `perf-check` 스킬 |
| 문항·템플릿 | `build-bank` 스킬 |
| 적·무기 | 문서·데이터·코드 3곳 일치 |
| 문서 | `new-doc` 스킬의 인덱스 등록 |
| 빌드·배포 설정 | Netlify 순서 전체 재현 |

**하나라도 실패하면 완료가 아니다.** 실패를 보고하고 멈춘다.
