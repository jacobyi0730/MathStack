## 14. UI / UX

### 14.1 화면 흐름

```
타이틀 → 학년/학기 선택 → 캐릭터 선택 → (용사 이름 입력) → 게임 → 결과
                                                          └ v2: 학급 코드 (§15.6)
```

### 14.2 인게임 HUD

```
┌────────────────────────────────────────────────────┐
│  ⏱ 04:32        Lv.11   ████████░░  237/305        │  ← 상단: 시간·레벨·경험치 바
│  ❤ 82/120                          ⚔ 342  ✓ 9/11   │  ← 체력 / 처치 수 / 정답 수
├────────────────────────────────────────────────────┤
│                                                    │
│                     [ 게임 화면 ]                   │
│                                                    │
├────────────────────────────────────────────────────┤
│  무기    [탄소 고리 Lv.2][란타넘 창][ ][ ][ ][ ]     │  ← 무기 6슬롯 + 레벨
│  보조무기 [네오디뮴 자석 Lv.3][프라세오디뮴][ ][ ]   │  ← 보조무기 6슬롯 + 레벨
└────────────────────────────────────────────────────┘
```

HUD 상단에는 1~3챕터 진행도를 함께 표시한다. 0~3분은 1챕터, 3~6분은 2챕터, 6분 이후는 3챕터다.
배경도 챕터별로 바뀐다. 1챕터는 기본 주기율표 필드, 2챕터는 차가운 청색 필드, 3챕터는 보라색 붕괴 필드로 전환해 진행도를 화면만 봐도 알 수 있게 한다.

점수도 HUD에 표시한다. 점수는 `생존 초 + 처치×10 + 총 경험치 + 1차 정답×100 + 레벨×25`로 계산한다. 서버 없이도 즉시 비교할 수 있어야 하므로 결과 화면에는 localStorage 기반 랭킹 TOP 5를 함께 보여준다.
타이틀 화면에서도 localStorage 기반 랭킹 TOP 5를 볼 수 있다. 랭킹은 용사 이름과 점수를 함께 표시하며, 같은 이름으로 여러 번 플레이한 경우에는 최고 기록 하나만 남긴다.

생존 중 브라우저를 닫으면 이어하기 데이터가 localStorage에 자동 저장된다. 저장 범위는 학년/캐릭터 선택, 생존 시간, 체력, 레벨/경험치, 무기·보조무기, 보스 진행도, 초월 수련 진행도다. 일반 적 무리는 저장하지 않고 이어하기 시 새 필드 상태로 재개한다.

### 14.2.1 전투 피드백

적이 피해를 입으면 적 머리 위에 **데미지 숫자**가 짧게 떠오른다. 숫자는 전투 리듬을 방해하지 않는 작은 노란 텍스트이며, 0.6초 안팎으로 위로 이동하며 사라진다.

- 표시값은 실제 적용된 피해량을 반올림한 값이다.
- 숫자는 캐릭터와 투사체 위에 그려져야 한다.
- 게임 루프에서 새 객체를 만들지 않도록 고정 크기 풀을 재사용한다.
- 초반 밸런스 확인에도 쓰인다. 라돈이 기본 수소 화살 한 방에 죽는지 플레이어가 즉시 볼 수 있어야 한다.

### 14.3 문제 모달

- 게임이 **완전히 정지**한다. 배경은 40% 어둡게 처리.
- 시간 제한과 남은 시간 링 게이지는 표시하지 않는다. 아이가 문제를 충분히 읽고 풀 수 있게 한다.
- 문제 글자 크기 최소 **24px**. 4지선다는 2×2 그리드, 버튼 최소 높이 56px (터치 대응).
- 보기 번호는 **답과 붙여 쓰지 않고 원형 배지로 분리한다.** `1. ` 을 답 앞에 이어 붙이면 답이 소수일 때 `2. 2.5` 가 되어 어디까지가 번호인지 읽힐 수 없다.
- 번호 자체는 지우지 않는다 — 숫자 키 1~4 로 고르는 키보드 조작(§14.4)이 이 번호를 가리킨다. 배지는 스크린 리더에서 숨긴다.
- 답 글자(22px, 큰 글자 모드 28px)는 번호 배지(18px)보다 크게 둔다. 눈이 번호가 아니라 답에 먼저 닿아야 한다.
- 세로 FHD 모바일 화면에서 잘리지 않도록 모달은 뷰포트 안에서 최대 높이를 제한하고, 내용이 길면 패널 내부에서 스크롤한다.
- 정답 시 초록 플래시 + 0.3초, 오답 시 붉은 흔들림 + 해설 카드 슬라이드 인.
- 분수는 `3/5`가 아니라 **세로 분수 형태**로 렌더한다. 초등 교과서 표기를 따른다.
- 정답 또는 재도전 종료 후에는 문제 모달을 닫고 **스킬 선택 창**을 띄운다. 아이가 보상을 고르기 전까지 전투는 멈춘 상태를 유지한다.

### 14.3.1 스킬 선택 창

스킬 선택 창도 퀴즈 모달과 같은 모바일 높이 기준을 따른다. 긴 스킬 설명이나 큰 글자 설정 때문에 카드가 늘어나면 화면 밖으로 밀어내지 않고 패널 내부에서 스크롤한다.

- 1차/재도전 정답은 **3개 선택지**, 재도전 오답은 **2개 선택지**를 보여준다.
- 각 선택지는 종류(무기/보조무기/각성), 이름, 원소 기호 또는 수학적 근거, 적용 후 레벨, 각성 짝꿍을 표시한다.
- 선택 즉시 무기·패시브·각성 효과를 적용하고 HUD에 반영한 뒤 전투를 재개한다.
- 각성 조건을 만족한 후보는 선택지 첫 칸에 우선 배치한다.
- 일반 보상 3택은 랜덤 1개와 현재 보유 무기 강화 또는 각성 짝꿍 보조무기 2개로 구성한다.

학년 바꾸기는 실제 타이틀 흐름으로 돌아가야 한다. 앱 시작 시 타이틀 → 학년/범위 선택 → 캐릭터 선택을 거치며, 학년은 1~6학년을 지원한다.
모바일 브라우저에서는 주소창과 하단 바가 실제 화면 높이를 줄이므로, 타이틀·학년 선택·캐릭터 선택·설정·결과 화면은 `100dvh` 기준 안에서 자체 스크롤되어야 한다. 메뉴 진행 버튼이 화면 아래에 잘려 도달할 수 없으면 실패다.

### 14.4 접근성

- 색만으로 정보를 전달하지 않는다 (정답/오답에 아이콘 병기).
- 모든 텍스트 명도 대비 4.5:1 이상.
- 퀴즈는 기본적으로 시간 제한이 없다.
- 화면 흔들림·섬광 효과 강도 조절 옵션.

### 14.5 엔티티 모양 체계

화면 위의 모든 것이 **원 + 눈**이면 무엇이 나를 쫓고 무엇을 주워야 하는지 색으로만 갈린다. 모양으로 먼저 갈리게 한다.

| 모양 | 무엇 | 그리는 법 |
| --- | --- | --- |
| **원 + 눈** | 플레이어, 적, 보스 | 몸통 원 + 테두리 + 눈 2개 + 액세서리 |
| **네모** | 원소 램프(상자) | 둥근 사각 + 뚜껑선 + 세로 끈. **눈 없음** |
| **아이콘** | 즉시 발동 아이템, 투사체 | 원 배지 + 기능을 나타내는 이모지. **눈 없음** |
| **장판** | 오라, 파동 | 반투명 채우기 + 밝은 테두리. 아래 적이 비쳐야 한다 |

**눈은 살아 있는 것에만 붙인다.** 이 규칙 하나가 "쫓아오는 것 / 내가 가서 먹는 것"을 가른다.

이모지는 본문 글꼴이 아니라 **컬러 이모지 글꼴**로 그린다. 크기는 반지름 × 1.9 이되 **26px 이상 40px 이하**로 묶는다 — 반지름 5짜리 수소 화살도 읽혀야 하고, 반지름 48짜리 마그네슘 폭탄이 화면을 덮어도 안 된다.

> **하한 26px 은 실제 화면에서 뽑은 값이다.** 헤드리스 브라우저로 게임을 띄워 확인한 결과 14px 은 형체를 알 수 없었고, 22px 도 적(지름 32)보다 작아 묻혔다.

**이모지는 26px 에서 읽히는 것만 고른다.** 획이 많은 글리프는 뭉갠다 — 수소 화살이 🏹 였을 때 활도 화살도 보이지 않아 💧 로 바꿨다(수소가 물의 원소라 의미도 맞는다). 새 아이콘을 넣을 때는 **반드시 게임 크기로 렌더해서 눈으로 확인한다.**

| 아이템 | 아이콘 | 무기 | 아이콘 |
| --- | --- | --- | --- |
| 아이오딘 방울 | ❤️ | 수소 화살 | 💧 |
| 네오디뮴 자석 | 🧲 | 네온 광선 | ⚡ |
| 이리듐 운석 | 💣 | 탄소 고리 | 💠 |
| 세슘 시계 | ⏱️ | 마그네슘 폭탄 | 💥 |
| 인 점화 | 🔥 | 황금 나선 | 🌀 |
| 금 보호막 | 🛡️ | 붕소 산탄 | ✨ |

각성 무기는 원형과 다른 아이콘을 쓴다 (☄️ 🔆 💎 🌪️ 🔰 🌋 🌟 🎆). **아이템과 무기가 같은 이모지를 쓰지 않는다** — 회귀 테스트로 막는다.

양성자 조각은 이모지를 붙이지 않는다. 조각은 색과 크기로 이미 갈리고, 화면에 가장 많이 깔리는 것이라 글자를 얹으면 오히려 시끄러워진다.

이리듐 운석은 화면 안이 아니라 **맵 전체**의 적에게 피해를 준다. “폭탄” 아이템은 보이는 화면만 정리하는 효과보다 전장 전체를 정리하는 기대가 강하므로, 피해량은 유지하되 초반 적 수와 HP를 함께 낮춰 남발 리셋이 되지 않게 한다.
즉시 발동 아이템이 필드에 나오면 화면 위 중앙에 “이리듐 운석이 나왔습니다” 같은 큰 알림을 2초가량 띄운다.

산소 파동·철 결계처럼 **장판으로 그려지는 무기**는 아이콘이 화면에 나오지 않는다. 값은 남겨 둔다 — 나중에 HUD나 스킬 선택 창에서 쓸 자리다.
