## 14. UI / UX

### 14.1 화면 흐름

```
타이틀 → 학년/학기 선택 → 캐릭터 선택 → (용사 이름 입력) → 게임 → 결과
                                                          └ v2: 학급 코드 (§15.6)
```

### 14.2.1 전투 피드백

적이 피해를 입으면 적 머리 위에 **데미지 숫자**가 짧게 떠오른다. 숫자는 전투 리듬을 방해하지 않는 작은 노란 텍스트이며, 0.6초 안팎으로 위로 이동하며 사라진다.

- 표시값은 실제 적용된 피해량을 반올림한 값이다.
- 숫자는 캐릭터와 투사체 위에 그려져야 한다.
- 게임 루프에서 새 객체를 만들지 않도록 고정 크기 풀을 재사용한다.
- 초반 밸런스 확인에도 쓰인다. 라돈이 기본 수소 화살 한 방에 죽는지 플레이어가 즉시 볼 수 있어야 한다.

### 14.3 문제 모달

- 게임이 **완전히 정지**한다. 배경은 40% 어둡게 처리.
- 시간 제한과 남은 시간 링 게이지는 표시하지 않는다. 아이가 문제를 충분히 읽고 풀 수 있게 한다.
- 문제 글자 크기 최소 **24px**. 4지선다는 2×2 그리드, 버튼 최소 높이 56px (터치 대응).
- 보기 번호는 **답과 붙여 쓰지 않고 원형 배지로 분리한다.** `1. ` 을 답 앞에 이어 붙이면 답이 소수일 때 `2. 2.5` 가 되어 어디까지가 번호인지 읽힐 수 없다.
- 번호 자체는 지우지 않는다 — 숫자 키 1~4 로 고르는 키보드 조작(§14.4)이 이 번호를 가리킨다. 배지는 스크린 리더에서 숨긴다.
- 답 글자(22px, 큰 글자 모드 28px)는 번호 배지(18px)보다 크게 둔다. 눈이 번호가 아니라 답에 먼저 닿아야 한다.
- 정답 시 초록 플래시 + 0.3초, 오답 시 붉은 흔들림 + 해설 카드 슬라이드 인.
- 분수는 `3/5`가 아니라 **세로 분수 형태**로 렌더한다. 초등 교과서 표기를 따른다.
- 정답 또는 재도전 종료 후에는 문제 모달을 닫고 **스킬 선택 창**을 띄운다. 아이가 보상을 고르기 전까지 전투는 멈춘 상태를 유지한다.

### 14.3.1 스킬 선택 창

- 1차/재도전 정답은 **3개 선택지**, 재도전 오답은 **2개 선택지**를 보여준다.
- 각 선택지는 종류(무기/패시브/각성), 이름, 원소 기호 또는 수학적 근거, 적용 후 레벨을 표시한다.
- 선택 즉시 무기·패시브·각성 효과를 적용하고 HUD에 반영한 뒤 전투를 재개한다.
- 각성 조건을 만족한 후보는 선택지 첫 칸에 우선 배치한다.

### 14.4 접근성

- 색만으로 정보를 전달하지 않는다 (정답/오답에 아이콘 병기).
- 모든 텍스트 명도 대비 4.5:1 이상.
- 퀴즈는 기본적으로 시간 제한이 없다.
- 화면 흔들림·섬광 효과 강도 조절 옵션.
