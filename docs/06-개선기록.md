# 06. 개선 기록

> 한 줄 요약 — 플레이 테스트와 사용자 피드백으로 바뀐 기획 결정을 누적한다.

## 1. 기록 규칙

기능 개선이나 기획 추가는 구현과 함께 아래 세 곳에 남긴다.

| 위치 | 기록할 것 |
| --- | --- |
| 기획 문서 | 변경된 정본과 판단 근거 |
| `Tasks/T-XXX-*.md` | 작업 범위, DoD, 결과 메모 |
| `TodoList.md` | 완료 상태와 배정 이력 |

## 2. 개선 이력

| 태스크 | 개선 | 결과 |
| --- | --- | --- |
| T-029 | 월드 래핑, 투사체 사거리, 퀴즈 후 스킬 선택 | 토러스 맵과 레벨업 보상 흐름 완성 |
| T-030 | 데미지 숫자, 스킬 설명, 초반 밸런스 | 전투 피드백 강화와 초반 처치 템포 완화 |
| T-031 | 기획 문서 분리와 기록 지침 | 기획 허브, 6개 세부 문서, AGENTS 기록 규칙 추가 |
| T-032 | MathStack기획서 허브화 | 900라인 이상 전체본을 목차형 허브 문서로 축소 |
| T-033 | 기획서 상세 이관 보정 | 원본 기획서 상세 표와 판단 근거를 01~05 문서로 재배치 |
| T-034 | 근접 무기 범위, 접촉 피해, 퀴즈 시간 제한 | 탄소 고리·철 결계 반경 확대, 접촉 피해 체감화, 퀴즈 타이머 제거 |

| T-036 | 퀴즈 보기 가독성 | 보기 번호를 원형 배지로 분리해 소수 답과 섞이지 않게 함. 퀴즈 모달 DOM 테스트 실제 실행 |
| T-037 | 엔티티 모양 체계와 아이콘 | 상자는 네모, 아이템·투사체는 이모지, 오라·파동은 반투명 장판. 눈은 살아 있는 것에만 |

## 3. 앞으로 추가할 때

새 개선이 들어오면 이 표에 한 줄을 추가하고, 해당 영역 문서에도 상세를 반영한다.
