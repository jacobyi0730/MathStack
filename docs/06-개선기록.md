# 06. 개선 기록

## 1. 기록 규칙

기능 개선이나 기획 추가는 구현과 함께 아래 세 곳에 남긴다.

| 위치 | 기록할 것 |
| --- | --- |
| 기획 문서 | 변경된 정본과 판단 근거 |
| `Tasks/T-XXX-*.md` | 작업 범위, DoD, 결과 메모 |
| `TodoList.md` | 완료 상태와 배정 이력 |
